## §零 一句话方案

**把遗物从「6 种效果 × 5 个时机」的数值排列组合，重置成 33 件各占一个生态位的六轴体系**：数值锚只留少量做安全垫，大头换成触发互动、资源转换、规则改写、局外成长、风险代价——每一件拿到手都应该让玩家说「哦，这件会改变我打法」，而不是「又是一个 +X」。

---

## §一 病根诊断：为什么现在的遗物「都一样」

把现 25 件按**效果语义**聚类（不看名字看作用）：

| 聚类   | 件数    | 成员                              |
| ---- | ----- | ------------------------------- |
| 加力量  | **5** | 破碎圣油瓶 / 磨刀石 / 锈蚀护符 / 毒压表 / 锈蚀冠冕 |
| 加格挡  | **5** | 脏绷带 / 红泪戒指 / 隔热砖 / 第三捧灰 / 锈念珠   |
| 加充能  | **5** | 凹痕线圈 / 压力表 / 血齿轮 / 炉心余烬 / 唱诗班电池 |
| 回血   | **3** | 泛黄照片 / 铁口粮 / 朝圣者之铃              |
| 清污染  | **2** | 净化滤芯 / 圣油灯                      |
| 开局过牌 | **2** | 寻锈杖 / 齿轮币                       |
| 敌方减益 | **1** | 回声号角                            |
| 条件伤害 | **1** | 炉心                              |

22 件掉落件里 **19 件是「时机 × 数值」的排列组合**——效果 kind 只用了 block / heal / applyBuff(strength) / draw / gainCharge / gainPollution 六种，碰的全是同一根轴：**数值增益**。玩家拿到任何一件，体验只有「数值大一点 / 小一点」的区别。

而引擎里现成的能力大量闲置：`onHit` / `onBlock` / `onGainCharge` 这些时机只有卡牌在用；坚韧、荆棘、胆怯、回血印记这些 Buff 池资产遗物一件都没碰；地图层（战斗胜利、层推进、商店、跳卡）完全是空白；全部 25 件里带代价的只有锈蚀冠冕一件。

## §二 设计原则：六轴生态位模型

重置后每件遗物必须**至少占一个独占生态位**（可以多轴复合，但不允许「纯数值、纯通用、无互动」三无件）：

| 轴      | 定义                                   | 玩家体验                       |
| ------ | ------------------------------------ | -------------------------- |
| ① 数值锚  | 稳定正收益、直白                             | 「安全垫」——三选一时永远有保底，但不会是激动的选择 |
| ② 触发互动 | 挂在动作上（命中 / 击杀 / 受击 / 回血 / 消耗 / 获得格挡） | 「这件在盯着我做什么」——打法会绕着它长       |
| ③ 资源转换 | 污染 / 充能 / HP / 能量之间的汇率               | 「我在经营一台机器」——串起跨系统决策        |
| ④ 规则改写 | 改一条战斗运行规则（T3 专属）                     | 「拿到就换打法」——本局 Build 的分水岭    |
| ⑤ 局外成长 | 挂在地图层（战后 / 层间 / 商店 / 跳卡）             | 「整局都在变强」——把遗物从战斗拉进一局人生     |
| ⑥ 风险代价 | 强效果 + 明码标价的代价                        | 「敢不敢拿」——决策张力               |

配套三条硬规矩：

1. **通用性优先**：遗物「全部可选、不拦截」（docs/59 已裁定）的前提下，「拿了白板」的体验要尽量少。职业专属机制件（充能、卖血）后置到 T2+，玩家那时已理解系统、相性标注足以引导。
2. **每档一个职能**：T1 = 教学件（每轴一件，首胜三选一就开始展示系统深度）；T2 = 化学件（与职业、流派开始反应）；T3 = 规则件（拿一件换打法）。
3. **数量从 25 → 33**：T1 池 8→10、T2 池 9→12、T3 池 5→8。三选一的组合空间从 C(8,3)=56 涨到 C(10,3)=120，重开体验质变；当铺池（T1+T2）从 17 件涨到 22 件。

## §四 新阵容总表（33 件）

- 8 件里 7 件是规则改写或局外成长，1 件风险件（红王冠）。原 T3 五件全是「数值更大的 T1 件」，重置后 Boss 掉落拿到的一定是「换打法」的件。
- **燔祭之书是有预谋的**：docs/59 刚给 12 张全场持续 power 卡统一加了 `exhaust`，这些牌打出去就没了——燔祭之书让消耗本身有回报，直接盘活一个流派，是对 v1.1 卡池结构的接力设计。
- **熔炉之心把「留充能打伤害」和「泄充能打爆发」变成每回合的真实决策**：充能全局每点 +1 攻击伤，憋到 5 爆一次 AoE 5 伤再减半回 2~3，数值平衡空间大，首版数值纯猜。
- **红王冠重做了风险件的决策模型**：原版「+3 力量 +15 污染」是一次性买卖（拿的瞬间决定），新版「每回合 +1 力量 +3 污染」是持续拉锯——配圣油灯/泄压阀可以长期吃力量、配毒压表直接踩 80 线，代价是每回合污染临界 −2 HP 的持续失血。与超级大畸变特性（污染无上限）组合时成长最猛，哨兵重点关注。
- 淬火怀表如成本失控，降级版「第一次受 HP 伤害时获得 2 层力量（不减伤）」退回中成本，机制戏剧性保留七成。

## §六 池子与获取结构调整

1. **T1 ≥6 件约束**照旧满足（10 件），validator 不用动。
2. **当铺池**（T1+T2）扩到 22 件，典当事件的随机性同步质变。
3. **解锁件**：`engineer_first_clear` 空出的解锁位建议挂给**双重钟摆**（同样是「结算翻倍」主题，机士玩家的毕业礼）；`three_classes_clear` 位继续留给朝圣者之铃（全通后才配「朝圣完成」）。新解锁条件**不新增**（成本控制）。
4. 其余获取规则（同种子同结果 / 不可重复持有 / 锈蚀二选一）全部不动。

## §九 待甲方裁决项

1. **T1 件数**：本方案 T1 = 10 件（原 8）。若想控制首批工作量，可先落 8 件（砍完好之镜、黄铜哨子，后续补），池子约束 ≥6 不受影响。
2. **炉心余烬的处置**：移除（本方案）还是保留数值件做充能锚？若保留，建议改为「战斗开始 +3 充能；本场你第一次过载时反噬无效」（每日一免的戏剧件，中成本），生态位与熔炉之心错开。
3. **空转齿轮 vs 其他第 10 件**：「回合结束未打出攻击牌 → 抽 1 张」教的是纯防回合。若嫌节奏太慢，备选「学徒手册：战斗开始，手牌中每有一张技能牌 +1 格挡」（需要新的手牌计数条件，中成本）。
4. **身份件轻翻新**（不阻塞，纯可选）：破碎圣油瓶加一句「本场你的第一次卖血，回复 1 HP」——把「洒出来的那一半喂了刀」从一次性数值变成持续身份感。动身份件违反现行铁律，明示裁决才动。


1. **淬火怀表降级预案**：受击减半要走伤害管线，若第四批排期吃紧，先落降级版（不减伤、只给 2 层力量，中成本），减半版后补。

## §十 结语

这套方案的核心不是「把 25 件换成 33 件」，而是**把设计空间从一根轴（数值增益）撑开成六根轴**。玩家第二局、第三局拿到同一件遗物时，体验应该是「这件逼我用另一种方式打」——磨刀石逼你规划第一击、泄压阀逼你踩污染红线、燔祭之书逼你重新评估每一张消耗牌、朝圣者之铃让每一场胜利都在付利息。

数值全部是首版猜测，方向问题（同质化、生态位空白）才是本方案要解决的——按老规矩，数字交给哨兵和真人实测。

**请甲方重点裁决**：§九 五项 + 整体方向是否认可。认可后程序侧按 §八 分批落地。
