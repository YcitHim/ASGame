## 二、🔴 阻塞门禁：失控线爆发流**结构上无法成型**

按 §10 口径 b 跑 400 局：

|| 结果 | 参考线 |
|---|---|---|
| 出现率 | **0.0%（0 / 400）** | ≥15% |
| 对应局胜率 | —（无样本） | ≤ 全局 +15pp |

**根因（程序侧定位，非随机、非 AI）**：当前线性地图只有 **1 个祭坛节点**（n5），且每个祭坛**只允许附着 1 枚强化**（一次即离开）。
=> **一局最多持有 1 枚强化**，而「血怒 + 低血沸腾」需要在**同一张牌上同时挂两枚**。
**结论：这个流派在现版本里不只是 sim 跑不出来——玩家在实际游戏里也拿不到。** P3 门禁第一条（流派可成型）现在**不可达**。

### 请策划选一个解法（程序按选项实现）

| 选项 | 做法 | 侵入性 | 备注 |
|---|---|---|---|
| **A** | 线性地图加第二个祭坛（例如把 n4 休息点改为祭坛，或 n4/n5 都保留） | 最小（改一行数据） | 0.5 各流派都能多拿 1 枚强化，整体强度会上升 |
| **B** | 精英战除了掉遗物，额外给一次「强化三选一」 | 中（节点结算逻辑） | 主题上也顺（精英 = 强化的来源） |
| **C** | 等 P5 分支地图（祭坛权重 15%）：一局可能经过 2 个祭坛 | 无（等后续阶段） | P3 门禁需顺延到 P5 才能评 |
| **D** | P4 的 5 个事件里放 1~2 个给强化 | 中（事件系统还没做） | 与 P4「内容铺量」合并做 |
| **E** | 允许「同一祭坛同时附着 + 重铸」（仍只有 1 枚强化） | 无效 | **解决不了**（组合需要 2 枚） |

> 程序倾向 **A（最快）** 或 **B（最贴主题）**；若选 C，则 P3 门禁第一条应明确「顺延至 P5」，不要挂在 P3 上。

### Q1. 「机制卡」的判定口径（appliesTo 推导依据）
docs/23 §1 用「机制卡且费用 ≥2」描述 `lighten`、「攻击类机制卡」描述 `rustbite` / `bloodwage`，但 `appliesTo` 在数据里是**卡牌 id 白名单**，需要程序翻译。

- `lighten` = 该集合中**基础费用 ≥2** 的卡（redtear / overloadstrike / plaguesurge / bloodstorm / exsanguinate / bloodwall / lastbreath / crimsonpact / immortality）
- `rustbite` / `bloodwage` = 该集合中的**攻击类**（bloodbolt / redtear / overloadstrike / bloodflail / plaguesurge / bloodstorm / exsanguinate / veinburst / rustspray）
