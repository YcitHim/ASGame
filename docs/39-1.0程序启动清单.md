## 1. 1.0-A · 遗物系统扩展与随身遗物

### 1.1 引擎前置（先做，约 0.5~1 天）

| # | 改动 | 落点 | 说明 |
|---|---|---|---|
| A-1 | `RelicDefinition.tier`（1/2/3）+ `unlockCondition` 复用 | `core/registry/content.ts` + validator schema | 起始池筛选、精英池筛选取自 tier |
| A-2 | **Buff 时长字段落地**（还 D-4 技术债） | `resolve.ts` `applyBuffToTarget` 读 `effect.duration ?? buff 默认` | `echo_horn`「全体 1 回合易伤」需要 duration=1，当前硬编码 2 |
| A-3 | 遗物触发多效果 / 目标 `allEnemies` 打通 | `resolveEffects` | `echo_horn` / `furnace_heart`（onTurnEnd + charge≥8 + 全体 3 伤）|
| A-4 | 反向条件可用 | `not` + `tookDamageThisTurn`（均已存在） | `third_ash`「本回合未受伤」直接组合，无需新代码 |
| A-5 | `onSell` 触发内可 `draw` / `gainCharge` | `resolveEffects`（同谱系） | `gear_coin` / `blood_gear` |
| A-6 | meta 解锁条件新增 `three_classes_clear` | `stores/meta.ts` + `isContentAvailable` 调用方 | `pilgrim_bell` 用；第三职业上线后才有意义，先留管线 |

### 1.2 内容（21 件，纯 JSON + i18n）

- T1 起始池 8 件（含下放 3 件）：`blood_pump` / `redtear_ring` / `pressuregauge` / `whetstone` / `old_photo` / `bandage` / `gear_coin` / `rust_dowsing`
- T2 常规池 9 件（含现有 `rust_charm`）：`saint_bulb` / `venom_gage` / `insul_brick` / `blood_gear` / `purge_filter` / `echo_horn` / `iron_rations` / `third_ash`
- T3 稀有池 4 件：`choir_battery` / `rust_crown` / `furnace_heart` / `pilgrim_bell`
- i18n：每件 name / desc / flavor（flavor 用策划表原文）；validator 校验 tier 合法、效果 kind 在白名单。

### 1.3 起始配置重构

- 职业 JSON `startRelics` 改为**身份件固定 1 件**（血械 `broken_oil` / 炉心 `dentedcoil`）；原第 2 件下放 T1 池。
- 职业选择页新增「随身遗物」栏：T1 池 8 选 1（与难度同屏）；选择写入存档（`RunState` 新增 `companionRelic` 或并入 `createRunState` opts → 存档 **SCHEMA_VERSION 6→7** + 迁移）。
- `run.startRun(classId, seed, difficulty, companionRelic)`；sim 策略默认取池内首个可用件，保证双职业复跑可比。

### 1.4 验收

- validator：遗物 21 件通过；单测：tier 入池 / 随身遗物进战斗 / duration=1 易伤 / 三件组合条件触发。
- 复跑 400 局：区间 45~65%；超上限按 docs/37 §一.5 预案（先 `venom_gage` 2→1，再精英三选二）。
- 真人：难度 + 随身遗物同屏可点，开局能感到「选了就不一样」。
- golden：`golden-branch` 等若受起始遗物变化影响需重录，哈希入档。

## 5. 程序侧疑问（开工前请裁定）

1. **随身遗物与「继续远征」**：读档时若随身遗物已被之后的版本下架/改名，是否回退到身份件？（程序默认：找不到就跳过那件，不阻断读档。）
2. **A-4 反向条件**：`third_ash` 的「本回合未受伤」是否把「血量未变但被格挡」也算未受伤？（当前 `tookDamageThisTurn` 只在**掉血**时置真，与 docs/16 P2.3 血迹自伤口径一致。）
3. **A-2 Buff 时长**：`echo_horn` 的 1 回合易伤是在「施加后立刻开始计时」还是「敌人行动后开始」？（程序默认沿用现有 Buff 结算时序。）
4. **T3 掉落来源**：`choir_battery` 标「锈喉掉落」——是否要新增 Boss 遗物槽（当前 Boss 不给遗物），还是先并入精英/事件池？（新增槽会改奖励流程，需拍板。）
5. **解锁式遗物与旧档**：`pilgrim_bell` 这类新解锁项，旧档（已三职业通关但 meta 无记录）是否补发？（docs/36 口径：不回溯发放。）
