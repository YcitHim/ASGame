## 一、0.1 收口（封版前想确认的 5 件小事）

### Q1. 敌人「称号」要不要补？
- **现状**：冻结的效果图 `battle-screen.html` 里，敌人名下方有一行称号（例如「精英 · 锈蚀回廊的布道僧」）；但实现里**只显示名字**。这是目前与 UI 基准稿唯一的可见偏差。
- **选项 A**：补上（每个敌人一条称号，UI 加一行小字，成本极低）。
- **选项 B**：不补，把效果图这一行视为示意、不作为基准。
- **建议默认**：A（保持与冻结基准一致）。
- **策划决定**：**按建议 A，补上**。称号文案由策划出（格式见 Q22），7 只敌人一次性给齐；UI 只加一行小字，不动布局锚点。

### Q2. 结算文案要不要正式化？
- **现状**：胜利页标题「战 利 品 / 远 征 胜 利」、死亡页「死 亡」与副标题（如「血肉归还于锈。」）目前是**程序写死的**，未进文案表。
- **疑问**：这是最终文案吗？需要调整措辞、还是要给更多情境文案（例如首次通关、被同一敌人杀多次）？
- **建议默认**：先确认现有措辞，0.5 再考虑情境化。
- **策划决定**：**按建议**。「战 利 品 / 远 征 胜 利 / 死 亡」与副标题「血肉归还于锈。」确认为 0.1 最终文案，冻结。情境化文案（首通、复仇）记入 0.5 候选，与 flavor 一起做。

### Q3. 卡牌「风味文本（flavor）」0.1 要不要？
- **现状**：卡面按 docs/08 §5 规格只有「费用 / 卡图 / 卡名 / 类型·关键词 / 效果描述」，**没有 flavor 位**；因此 30 张卡的 flavor 目前是 0 条。
- **选项 A**：0.1 不加（维持现状，封版最快）。
- **选项 B**：加 flavor（需改卡面布局加一行小字 + 补 30 条文案，属于 UI 基准变更）。
- **建议默认**：A，flavor 留到 0.5。
- **策划决定**：**按建议 A**。0.1 不加、卡面规格不动。0.5 做 flavor 时一并改卡面规格（调性见 Q21），作为一次正式的 UI 基准修订走冻结流程。

### Q4. UI 固定文案的多语言时点
- **现状**：按钮、战斗日志、关键词注解等约 **250 处中文是硬编码在组件里**（0.1 只有中文，无功能影响）。
- **疑问**：确认「0.1 允许硬编码，0.5 或 1.0 统一迁到 i18n key」吗？若要出海/多语言，越早迁越省。
- **建议默认**：0.1 维持硬编码，写进文档；多语言时点由策划定（建议 1.0 前）。
- **策划决定**：**0.1 维持硬编码**，在 docs/11 记一条技术债（i18n 迁移）。多语言时点定 **1.0 前统一迁移**；0.5 新增文案要求「内容文案（卡牌/敌人/事件）必须走 i18n key，UI 固定文案可继续硬编码」，控制债务增量。

### Q5. 失败后「重新远征」的语义确认
- **现状**：阵亡 → 结算页 → 「重新远征」（**整局作废、满血开新局**）或「返回标题」。
- **疑问**：0.1 确认维持「死亡即整局作废」吗？（重试本节点已按 Q14 顺延 0.5）
- **策划决定**：**确认维持**。死亡即整局作废，按钮文案「重新远征」表意准确，不改。

## 二、0.1 数值复查（数据都在，请确认是否接受后再封版）

### Q6. 模拟器胜率 53% 是否接受？
- **现状**：100 局模拟（AI 只会「能出牌就出、优先攻击」，不会留牌/算斩杀）→ **胜率 53.0%**、平均 16.8 回合、4 场战斗、平均承伤 83。倒在 Boss 46%。
- **疑问**：按 Q15 的「真人比 AI 高 10~20 个百分点」推算，真人约 65%~75%。这个难度对 0.1 合适吗？
- **建议默认**：维持（落在策划期望的 45%~60%）。
- **策划决定**：**接受，封版数值冻结**。53% 在期望区间，Boss 46% 死亡率带来足够的终局压力；真人 65%~75% 对首个版本「能通关但有压力」正合适。

### Q7. 单局实测时长
- **现状**：**需要你反馈真机实际时长**（模拟器不含选牌/祭坛决策时间）。
- **疑问**：是否落在 12~15 分钟目标内？超时的话按 Q16 优先压敌人 HP，请指定优先压哪个节点。
- **策划决定（含实测时长）**：**待真机掐表（打 2~3 局完整流程），判定规则先冻结**：≤15 分钟通过；超 15 分钟按此顺序压 HP——① 第二场普通战小怪（蚀肉锈虫群 / 铆钉重装兵，各 -10%）→ ② 精英锈蚀看守（-8%）→ ③ 锈喉（-5%）。Boss 永远最后动。

### Q8. 敌人防御现在真有存在感了吗？
- **现状**：修完 bug 后，锈蚀猎犬防御 6、锈蚀看守防御 12 会真实挡住你的伤害。
- **疑问**：实战中是否感觉到"这回合该抢伤害 / 该格挡"的取舍？还是觉得拖节奏？
- **策划决定**：**数值不动，等真机手感反馈再微调**。预案冻结：若反馈「拖节奏」，只动锈蚀猎犬 6→4；看守 12 是精英的立身之本，任何情况下不动。

### Q9. 污染与充能两条副线的存在感
- **现状**：模拟器 100 局里，充能类卡（充能 / 过载斩 / 赤契）出牌占比很低，AI 基本不碰；污染主要靠敌人施加。
- **疑问**：这是 AI 太笨，还是这两条线在 0.1 的内容量下确实偏弱？若是后者，0.5 需要加多少支撑卡？
- **策划决定**：**两者都有，主因是 AI 太笨**（充能要规划爆发回合、血契要算致死线，都超出当前 AI 能力），但内容量确实偏薄。0.1 不动。0.5 补量：**充能系 +3 张**（1 张充能来源、1 张充能消费爆发、1 张过载利用）、**污染系 +2 张**（1 张主动施加、1 张污染转收益），同步增强模拟器 AI 对充能的评分（可选工程项）。

### Q10. 一局最多 4 件遗物够吗？
- **现状**：起始 2 件 + 精英掉落 2 件 = 一局最多 4 件（4 件全部可获取）。
- **疑问**：0.5 是否增加遗物数量与获取点（商店 / Boss 后 / 事件）？
- **策划决定**：0.1 维持。0.5 遗物池 **4 → 8 枚**，获取点新增 **Boss 战后必掉 1 件**（三选一）与**事件概率获得**；**不做商店**（0.5 没有金币系统，重铸资源走 HP，见 Q15）。

## 三、0.5 内容设计疑问

### Q11. 首批「连锁内容」（亡语 / 反伤）的具体形态
- **背景**：0.5 第一件事是接入栈式效果队列（ADR-002 硬门禁）。接入范围由内容决定。
- **疑问**：首批要几张连锁卡？各是什么机制？（例如「亡语：抽 2 张」「反伤：受到攻击时对攻击者造成 3 点」）
- **策划决定**：首批 **3 个锚点**，刻意走最小闭环：
  1. **反伤卡「荆棘血痂」**（普通技能，1 费）：获得 2 回合「受攻击时对攻击者造成 3 点伤害」。验收中途插入与多段触发。
  2. **敌人亡语「蚀肉锈虫群」**：死亡时对玩家施加 3 点污染。验收 `UnitDied.clearedEffects` 与死亡后挂起动作。
  3. **连锁反应卡「以血还血」**（稀有攻击，2 费 8 伤）：若本回合受过伤害，额外 +6。验收「本回合事件回看」类条件。
  - 注：玩家侧「亡语」在单人战斗里语义不成立（没有友方单位），亡语先只做敌人侧。

### Q12. 蓄力类设计规范（0.1 的血泪教训）
- **背景**：0.1 的蓄力一开始只加力量、不保证接大招，导致「一直蓄力、没有压迫感」，且永久力量会滚雪球（曾 26→38 伤害）。
- **疑问**：是否把「蓄力必须声明强制后续招式；优先用限时/一次性增幅而非永久力量」写成 0.5 设计规范？
- **建议默认**：写成规范。
- **策划决定**：**按建议，正式升格为设计规范**：①一切蓄力必须声明 thenIntent（强制后续招式），无后续招式的蓄力设计一律打回；②增幅优先限时/一次性，永久力量类效果 0.5 起禁止新增。写入 docs/13 §4 并同步进敌人设计模板。

### Q13. 「血锈光环」验收卡的具体数值
- **背景**：Q18 定为「本场战斗内，你的所有攻击 +1」（稀有、污染系），用来验收「本场临时修饰」层。
- **疑问**：费用 / 稀有度 / 是否附带污染代价（例如获得 5 点污染）？
- **策划决定**：**稀有技能卡，2 费**：本场战斗中你的所有攻击 +1，**代价：获得 8 点污染**（污染系身份 + 双刃剑）。升级版：攻击 +2、污染代价不变。数值语义——它是「用污染表换全局增幅」的引擎卡，不是白给的。

### Q14. T2「血怒」的具体效果
- **背景**：0.1 顺延；0.5 要与「低血沸腾」形成连动闭环。
- **疑问**：血怒 = 低血时什么效果？（例如「HP<50% 时，此牌获得的强化效果翻倍」？）
- **策划决定**：**T2「血怒」：附着的牌在你 HP<50% 时打出，伤害 ×1.5（乘区，单次取整）**。闭环逻辑：低血沸腾（HP<50% 拆三段）管「段数」，血怒管「单段质量」，两者同槽附着即成型「失控线爆发流」——与 UI 失控线表现同源。禁止叠乘其他永久力量（配合 Q12 规范）。

### Q15. 「重铸」功能的规则
- **背景**：0.1 顺延的重铸，需要定义清楚才能实现。
- **疑问**：重铸 = 替换某张卡上的强化？随机洗掉换一个？消耗什么资源（金币 / HP / 遗物）？在哪个节点可用？
- **策划决定**：
  - **位置**：锻造祭坛新增第二功能「重铸」（与「附着强化」并列）。
  - **规则**：选一张**已附着强化**的卡 → 随机移除其 1 个强化 → 从同 tier 可附着池中随机换 1 枚。**随机洗，不自选**，保留 roguelike 风险感。
  - **消耗**：**5 HP**（血契主题；0.5 无金币系统），每局每个祭坛限 1 次。
  - 休息点「移除一张卡」与本功能同期做（docs/13 已并项）。

### Q16. 职业 2 的主题与机制主轴
- **疑问**：职业 2 走三系里的哪一系（充能爆发 / 污染毒蚀 / 血契肉搏）？核心资源与首职业的差异点是什么？
- **策划决定**：**充能爆发系，主题「机械飞升侧」**（与血械侍僧的血肉侧对偶）。核心差异一句话：**血械侍僧拿血换效果（资源 = HP），职业 2 拿回合换爆发（资源 = 节奏）**——充能是「延迟满足」资源，鼓励规划与空转蓄力回合。污染系保持为两职业共用的环境压力，不作为职业 2 主轴。职业名与卡池 0.5 第一阶段再定。

### Q17. 分支地图的粒度
- **疑问**：岔路是「每次二选一/三选一」吗？分支后是否汇合？节点类型池与权重如何？（0.1 的 `map` 数据结构已支持任意节点序列）
- **策划决定**：**轻度分支，不织网**：每层 2~3 条并行短路径，节点处**二选一**为主；路径在**精英后与 Boss 前各汇合一次**。节点类型池与权重：普通战 40% / 精英 15% / 休息 15% / 祭坛 15% / 事件 15%。0.5 仍为单幕。

### Q18. 事件铺量
- **疑问**：0.5 计划几个随机事件？事件形态是纯文本选择、还是含小战斗 / 赌博 / 交易？
- **策划决定**：**首批 5 个事件，纯文本选择**（不含小战斗）。每个事件 2~3 个选项，结果挂钩 HP / 污染 / 遗物 / 强化四类收益；其中至少 1 个「赌博式」（高回报高代价）、1 个「血契式交易」（付 HP 换遗物/强化）。

### Q19. 局外成长（meta 进度）
- **疑问**：0.5 是否引入局外解锁（新卡池 / 新遗物 / 难度层级）？还是保持纯单局 roguelike？
- **策划决定**：**引入轻量 meta，只做解锁式**：通关与特定成就解锁新卡、新遗物入池（例如「首通锈喉 → 解锁血锈光环入池」）。**不做任何永久数值成长**，单局公平性不破。

### Q20. 难度层级（进阶难度）
- **疑问**：是否要做类似「进阶 1~N」的可选难度？若做，靠什么加难（敌人 HP / 伤害 / 减少遗物 / 增加污染）？
- **策划决定**：**0.5 只做 1 档「锈蚀难度」**（通关后解锁）：敌人 HP +20%、伤害 +10%、精英遗物掉落三选一变二选一。进阶 1~N 留 1.0 再系统化。

## 四、文案与表现

### Q21. flavor 的调性（若 0.5 要做）
- **疑问**：一句话风格样例是什么？（魂系冷峻诗性 / 机械血腥陈述 / 宗教布道口吻？）
- **策划决定**：**魂系冷峻诗性为骨，带宗教布道残响**；短句、留白、不解释。样例（血之螺栓）：「圣油燃尽之后，血便是新的燃料。」0.5 铺量时按此样例校准。

### Q22. 敌人称号 / Boss 台词的写法
- **疑问**：称号格式（「定位 · 一句话来历」？）；Boss 是否要在蓄力 / 二阶段 / 死亡时各来一句台词？
- **策划决定**：
  - **称号格式确认**：「定位 · 一句话来历」。7 只敌人称号由策划随 Q1 一并交付（示例：蚀肉锈虫群 →「小怪 · 血肉里孵化的铁」）。
  - **Boss 台词：做，3 句**——蓄力 / 进二阶段 / 死亡各一句，冷峻短句（≤12 字）。样例：蓄力「听见了，锈在歌唱。」；二阶段「血肉，让位。」；死亡「锈……终于停了。」台词 0.5 与 flavor 同期进文案表，0.1 只做称号。

### Q23. 图鉴（占位入口已存在）
- **疑问**：0.5 是否做图鉴（卡牌 / 遗物 / 敌人收集与解锁）？还是继续占位？
- **策划决定**：**做最小版图鉴**：卡牌 / 遗物 / 敌人三栏，**见过即解锁**（不要求持有），条目含名称 + 描述 + 称号（与 Q1/Q22 文案复用）。入口复用现有占位按钮，不做成就页。
