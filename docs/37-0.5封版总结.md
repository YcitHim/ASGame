## 2. 0.5 新增的玩法（可直接实机体验）

### 2.1 连锁机制（P1/P2，docs/22 已列）

1. **反伤 · 荆棘血痂**：受到攻击时对攻击者造成固定伤害，多段攻击逐段触发，不吃力量/充能。
2. **亡语 · 蚀肉锈虫群**：死亡时对玩家施加污染。
3. **以血还血**：若本回合（含刚结束的敌方回合）受过伤害，额外造成伤害。

### 2.2 强化闭环（P3）

4. **血怒 × 低血沸腾 = 失控线爆发流**：HP<50% 时此牌伤害 ×1.5，同槽三段各乘一次。
5. **血锈光环**：本场战斗所有攻击 +N，代价污染——「本场临时修饰层」的首个真实写入方，走修饰符管线可追溯。
6. **重铸 / 剔除**：祭坛可随机同阶换强化（耗 5 HP，每祭坛限 1 次）；休息点可移除一张卡。
7. **残骸锻核**：精英战后追加强化三选一，**可附着到已强化过的牌** → 同卡双挂可达。

### 2.3 单局分叉（P4/P5）

8. **第二职业 · 炉心机士**：充能爆发系，「拿回合换爆发」；起始卡组 / 起始遗物 / 24 张专属卡；通关一次解锁。
9. **分支地图**：8 层骨架，精英后与 Boss 前各汇合一次；分支层 3 选 1（普 40 / 精 15 / 休 15 / 祭 15 / 事 15）。
10. **5 个随机事件**：纯文本 2~3 选项，含赌博式与血契交易式，结果挂钩 HP / 污染 / 遗物 / 卡 / 强化。
11. **图鉴最小版**：卡牌 / 遗物 / 敌人三栏，见过即解锁。

### 2.4 meta 与难度（P6，本次新增）

12. **解锁式 meta（T1）**：新遗物 **炉心余烬**（战始 +3 充能，炉心首通解锁）；**不朽之躯**（全程不打出任何血契牌通关解锁）；**红线协议**（单局触发 ≥3 次过载反噬仍通关解锁）；**血锈光环** 改为首通解锁。解锁项入 meta 存档，**禁永久数值成长**。
13. **锈蚀难度（T2）**：职业选择页同屏二选一，通关一次解锁。敌人 HP ×1.2 / 伤害 ×1.1 / 精英遗物三选一改二选一。

## 3. 架构与工程变化

- **栈式效果队列（ADR-002）全量接入**：中途插入（反伤每段后立即结算）与死亡清理（`UnitDied.clearedEffects` 真实非 0）。
- **修饰符管线直通难度**：锈蚀的敌人伤害倍率作为 `layer:"buff"` 的乘区进管线，`DamageDealt.layers` 可追溯到 `sourceId:"difficulty"`；normal 档不加修饰 → golden 回放锁定不受影响。
- **内容入池统一判定**：`isContentAvailable(unlockCondition, id, unlocked)` 一处收口卡奖 / 遗物池 / 事件掉落；core 只认 `RunState.unlocked` 快照，不反向依赖 meta 层。
- **成就埋点在事件流边界**：`CardPlayed.bloodPaid` / `Overloaded` 由 UI store 读取后写回 run 状态，core 不引入局外概念。
- **难度全链透传**：`RunState.difficulty → BattleConfig → BattleState/Draft → attackModifiers`，无分支特判。
- **存档 SCHEMA_VERSION 5→6**：`RunState` 新增 `unlocked / difficulty / usedBloodpact / overloadCount`，迁移链只补进度档、meta 槽不污染；旧档读入缺字段由 run store 双保险补齐。
- **内容唯一装载点**：`buildEnemyDefinition()` 继续保证新增敌人字段（如亡语）只改一处。

## 6. 遗留观察项（移交 1.0）

1. **血械 strike 占比**：普通档 400 局出牌 Top1 仍是 `strike`（10105 次），基础卡退休机制留到第三职业时统一评估。
2. **失控线爆发流出现率**：当前 9.8~10.5%（分支地图后已上抬），低于报表参考线 15%；1.0 复看获取点数量。
3. **精英场景直开偏差**：100% 胜率 / 承伤 14.4，仍超 docs/19 §3.2 的 70~90% / 25~40；根因是「典型卡组」定义（`bestReward` 贪心强于真人），待策划定义后再校准，非本次回归。
4. **锈蚀难度基线**：仅摸底一档（20.0% / 13.0%），1.0 若加第三档难度需重设参数。
5. **sim AI 估值**：仍弱于真人（不会留牌/算斩杀），所有 sim 数字以真人实测为终审（docs/27 口径）。
6. **第三职业**：基础卡退休 / 卡池轮换机制届时再评。
