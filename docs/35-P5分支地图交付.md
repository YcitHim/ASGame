## 一、地图结构（8 层，手写骨架 + 种子生成节点）

| 层 | 宽度 | 类型 | 说明 |
|---|---|---|---|
| l0 | 1 | battle | 入口必经战（早期遭遇池） |
| l1 | 3 | battle / rest / altar / event | **分支一**（早期遭遇池 + 5 事件池） |
| l2 | 1 | battle | 中期必经战（中期遭遇池） |
| l3 | 1 | elite | 铁锈看守 |

| l5 | 3 | battle / elite / rest / altar / event | **分支二**（中期遭遇池 + 5 事件池） |
| l6 | 1 | altar | **Boss 前汇合点** |
| l7 | 1 | boss | 锈喉 |

- **全局权重**（docs/14 Q17）：普通 40 / 精英 15 / 休息 15 / 祭坛 15 / 事件 15；每层只在自己的 kinds 里按权重抽。
- **生成**：generateActMap(act, seed) 用独立 map RNG 流，同种子同地图；节点 id = kind_层_序号，文案统一取 node.<kind>（docs/29 §二⑧ 命名表，已补 6 条 i18n）。
- **必经/汇合层（width=1）不需选择**，currentNode 自动生效；分支层（width≥2）必须 chooseNode。

## 二、状态与存档

- RunState：nodeIndex → **layerIndex + picked[]**（每层选中的候选下标）。
- 存档 **SCHEMA_VERSION 4→5**：旧档按 nodeIndex 近似落到同层，picked 置空（到分支层时重新选）。
- rollEncounter / rollEvent / 奖励种子的节点偏移全部改用 layerIndex。
- UI：MapView 改为逐层渲染，当前层候选可点「进入」，已过层显示「已通过 / 未选择」，未来层「未抵达」。

- **数值敏感点（已记录）**：分支让玩家可择优，整体强度上抬。经对照试验，两个汇合点的类型对胜率影响最大——
  - 两处都是休息 → 血械 77%（过易）
  - 精英后休息 + Boss 前祭坛（当前）→ 59%
  - Boss 前放真实战斗 → 36%（过难）
  当前取「精英后休息、Boss 前祭坛」，与原线性地图的 n4/n5 预算对齐。
- **P6 复锚**：全量复跑时以双职业同时落区间为准；炉心 45.3% 可能需要小幅回补。
