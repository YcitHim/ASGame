## 原方案核心要点（已吸收进本 docs）

- 主题：黑暗魂系 × 机械飞升 × 血肉科技 × 异变污染
- 三系机制：血契（卖血换强度）/ 充能（延迟爆发）/ 污染（双刃剑）
- 技术栈：Vue 3 + TS + Vite + Pinia；核心层纯 TS 零 DOM；DOM+CSS 动画；0.5 引入 PixiJS 特效层
- 差异化卖点：双轴构筑——横轴抓牌组合 + 纵轴单卡专精强化
- 首职业「血械侍僧」：30 张卡、起始 HP 66、能量 3、抽 5；卖血汇率锚 1HP≈3伤
- UI 基调：#12100E 深灰底 / #E8E0D0 骨白字 / #8A2B1F 血锈红 / #B08D4A 圣金
