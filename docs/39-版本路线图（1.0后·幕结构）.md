## §一 先认错，再讲理

**为什么 1.0 没有第二幕**：docs/37 立项时的取舍是「先把玩法撑宽（第三职业），再把世界撑大（第二幕）」——理由是锈语者的设计结论（蚀锈 DoT、召唤相性）应该成为第二幕敌人设计的**输入**而不是返工项。这个取舍本身我至今仍认为是对的。

**但我欠两句明白话**：
1. 叫「1.0」却只有一幕，版本号给了「成品」的预期，内容给的是「单幕」的现实——**这是策划的沟通失误，不是排期失误**。正确做法是在 docs/37 就写明「1.0 = 系统完备版，幕结构在 1.1/1.2」。
2. 「二期另行立项」这五个字太轻了，轻到它看起来像一句客套。本文把它落成正式路线。

## §三 转地图机制规格（幕间过渡系统）——现在定稿，v1.1 直接施工

这是「转地图」的全部规则，程序照此实现，不再有口径问题。

### 3.1 流程

```
击败第一幕 Boss（锈喉）
  → 战斗结算（照常：三选一奖励）
  → 【幕间过场】（新增画面，见 3.3）
  → 生成第二幕地图（8 层，结构规格见 3.4）
  → 玩家出现在第二幕起点，继续远征
```

**一档到底**：两幕是**同一局、同一存档**，不是两局拼接。SCHEMA_VERSION +1，幕字段（currentAct）入存档。

### 3.2 继承与重置表（核心规则）

| 项 | 过幕时 | 理由 |
|---|---|---|
| 牌组 / 升级 / 移除记录 | **全继承** | 构筑是玩家一局的资产，动它等于否定前半局 |
| 遗物（含随身遗物） | **全继承** | 同上 |
| 强化附着 | **全继承** | 同上 |
| 当前 HP | **继承，并回复上限的 25%** | 幕间是一次「喘息」，不是「重置」；回满会让第一幕 Boss 战后的残血失去意义，不回则第二幕开门就崩 |
| 最大 HP | 继承 | — |
| 污染 / 充能 | **清零** | 战斗内资源，战斗外不存续——这是三系机制自 0.1 起的一贯口径，过幕不破例 |
| 战斗 Buff（力量/易伤等） | 清零 | 战斗结束时本就清零，过幕只是重申 |
| 金币类资源 | 无（本作无金币） | — |
| 图鉴 / 成就 / meta | 照常累计 | 跨局系统不受幕影响 |

### 3.3 幕间过场（叙事 + 奖励）

一幕一次，三段式：

1. **过场文案**（一屏）：锈喉倒下 → 地板塌陷 → 坠入沉没圣堂。文案策划出，走 i18n。
2. **圣堂馈赠（三选一）**：① 回复 50% HP　② 免费升级 1 张牌　③ 从第二幕专属强化池随机获得 1 枚（附着机会照常）。——给玩家一次「为第二幕定向补强」的决策，代替「白捡的幕间奖励」。
3. **进入第二幕地图**。

### 3.4 第二幕地图结构规格

| 项 | 规格 | 与第一幕的差异 |
|---|---|---|
| 层数 | 8 层（第一幕 8 层含起点终点，第二幕同构） | 持平 |
| 节点构成 | 普通 ×4 / 精英 ×2 / 事件 ×2 / 休息 ×1 / 祭坛 ×1 / Boss ×1（首尾固定，中段分支） | 精英密度 +1（第二幕是「熟练者区域」） |
| 分支 | 中段至少 2 处分支，汇合点 ≥1 | 沿用 1.0 分支地图系统，零新机制 |
| 敌人 | 第二幕敌型 6~8 只，**召唤机制解禁首秀** | 全新敌池；第一幕敌人不出场（主题隔离：回廊的锈留在回廊） |
| 数值基准 | 敌人 HP / 攻击 ≈ 第一幕 × 1.35~1.5（立项时以 1.0 封版数据精调） | 匹配玩家过幕时的构筑强度（+Boss 奖励 +圣堂馈赠） |
| 休息点 | 仅 1 个（第一幕 2 个） | 第二幕的续航压力是设计的一部分 |

### 3.5 失败与胜利

- **第二幕战败**：本局作废（与一幕一致），结算页新增「最深层：第二幕 · 第 N 层」统计字段。
- **第二幕 Boss 胜利**：v1.1 阶段即通关（真结局留给 v1.2 第三幕），结算页标注「沉没圣堂已净」，成就 +1。
- **锈蚀难度**：两幕全程生效，参数不随幕变化。

## §五 v1.2 第三幕框架（只立框架，不做详案）

- **主题候选**：「锈心锻炉」（一切的锈从源头流出）或「飞升礼坛」（机械飞升的终点仪式）——立项时结合第二幕叙事落点定。
- **结构**：第三幕建议做**短而密**（5~6 层，敌人从两幕混合精锐池抽取 + 终局 Boss），避免 35 分钟一局的疲劳尾段。
- **终局**：真结局 Boss + 通关后解锁「无尽回廊」（可选，立项时评）。
- **明确不做**：第四幕。三幕是本作的完整结构，此后内容更新走「幕内扩容」（新敌/新事件/新职业），不再加幕。
