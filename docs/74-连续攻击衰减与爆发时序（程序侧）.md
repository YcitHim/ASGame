# 连续攻击衰减 + 爆发时序修正（程序侧 · 2026-10-09）

> 对应甲方两条口述指令：
> 1. 「玻璃大炮先把充能抽干了再判断卡牌的 ≥2 充能，应该改成先判断卡牌，再抽空充能。」
> 2. 「只有在充能增伤的情况下，多段伤害的增幅才 -50%（三段 300% → 175%）。其他情况下不变。
>    这是给玻璃大炮打的补丁。」
>
> **状态：已实装，四道门禁全绿（vitest 747/747，golden 14 盘）。**

---

## §一 修正：卡牌先算完，再抽空充能

**旧行为（bug）**：play-card 在结算卡牌效果**之前**就把充能清零，于是
- 活塞冲拳的「充能 ≥2 时额外造成 2 点」条件读到 0 → **第二段根本不发**（实机看到的「只显示一段」）；
- 自带泄能的牌（泄能重锤 / 泄压阀 / 紧急泄压）先被特性抽干 → 自己的 spendCharge 结算成 0。

**新行为**：卡牌的条件与 spendCharge 先按**出牌时的充能**结算，剩下的充能才由特性「一波打出去」收走。
收尾清零只收走**出牌瞬间那一笔**（chargeAtPlay），这张牌自己新攒的充能不会被误吞（火花塞 / 电击拳）。

### 顺带修掉的重复计算

充能只能算一遍：卡牌**自带** spendCharge → 充能按卡牌自己的汇率兑现，特性只再补「超负荷折功」（层数 ×5）；
卡牌**不带** spendCharge → 特性补「充能 + 超负荷折功」。

| 场景（16 充能 → 2 层超负荷） | 旧 | 新 |
|---|---|---|
| 泄能重锤（spendCharge ×3） | 0 + 折功挂不上 → **0 伤害** | 16×3 = **48** |
| 锅炉之怒（6 基础 + spendCharge ×2） | 6 + (16+10) = 32 | 6 + 10 + 32 = **48** |
| 活塞冲拳（3 + 条件 2） | 第二段不发 | 两段都发 |

## §二 新规则：连续攻击**只砍充能增伤**

    第 1 段的充能增伤 = 100%；第 2 段 ×0.5；第 3 段 ×0.25；第 4 段 ×0.125 …
    → 三段原本 300% 的充能增伤，变成 175%

关键限定（都是甲方口径）：
- **只砍「充能增伤」这一项**：卡牌自身的基础伤害、力量、强化、超负荷折功等**一概不动**；
- **没有充能增伤的攻击完全不受影响**（所以这条规则只对「充能流 + 多段」生效）；
- **只作用于玩家出牌**：敌人的多段普攻没有充能增伤，天然不吃这条。

### 「充能增伤」认哪几处

| sourceId | 出处 | 是否衰减 |
|---|---|---|
| trait:（特性id）:firstAttackCharge | 玻璃大炮「一波打出去」 | 砍 |
| charge | 普通充能加伤（chargeTarget = attack 的炉心） | 砍 |
| charge:hybrid | 铁皮王八的防御向充能改道 | **不砍**（理由见 §四 ①） |

### 「段」怎么数（这里有个坑）

段数不是「卡面有几个 damage 效果」，而是**会同时结算的伤害效果数**：
- 蚀心之刃写成 7 @not(污染≥50) + 14 @污染≥50——两段**互斥**，永远只中一段，算**同一段**
  （顺带修掉旧日志把它标成「第 2/2 段」的错误）；
- 活塞冲拳的「充能 ≥2 额外 2 点」与第一段会同时发生 → 真·两段。

## §四 仍需你拍的 2 处

### ① 铁皮王八的「混合充能」要不要也砍？

铁皮王八的 chargeTarget = block：充能先全量进格挡，再分 ⌊充能÷2⌋ 给攻击——这也是「充能增伤」，
按字面应该一起衰减。**我先没砍**，因为有实测证据：

| | 不砍 hybrid | 砍 hybrid |
|---|---|---|
| golden-trait-turtle | 9 回合胜 | **107 回合胜**（10 倍拉长） |
| golden-trait-cannon | 8 回合胜 | 8 回合胜（完全无变化） |

玻璃大炮根本走不到 hybrid 这条路，砍它只是在惩罚防御盘。**要一起砍的话说一声，一行的事。**

### ② 递减是等比还是固定？

现在是**等比**：100% / 50% / 25% / 12.5%（三段 175%）。
如果你要的是「每段都减 50%」（100/50/50，三段 200%），改一个常数即可。
两段牌两种算法一样，只有 3 段以上有差别。

## §五 顺带修掉的两处旧账

1. **蚀心之刃的「段号」**：7/14 这种互斥写法以前会被引擎标成「第 1/2 段」「第 2/2 段」，
   现在它们算同一段（第 1/1 段），日志不再骗人。
2. **充能在多段里算两遍**（泄能类卡牌自己一点没兑现、特性全吃）——见 §一。
