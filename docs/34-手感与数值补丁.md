## 一、减重不能作用于活塞冲拳（bug）

**原因**：docs/32 给炉心卡扩展 `appliesTo` 时，`lighten`（减重）只补了**技能**，漏了攻击牌。

**修复**：`lighten.appliesTo` 补入炉心 10 张攻击牌（pistonjab / sparkplug / steambolt / chargedhammer / twinpistons / steamvent / boilerrage / punchthrough / coreoverload / teslacage）。

## 二、锈蚀护符与破碎圣油瓶定位冲突（程序方案，待追认）

**问题**：破碎圣油瓶 = 战始 +2 力量（一次性）；锈蚀护符 = 回合结束 +1 力量。玩家实测认为前者是后者的上位——开局即给、单次更多，短局里护符没有取用理由。

**程序处理**：把护符从「回合结束」改为「**回合开始**」——

| 遗物 | 原 | 新 |
|---|---|---|
| 破碎圣油瓶 | 战斗开始 +2 力量 | 不变 |
| 锈蚀护符 | **回合结束** +1 力量 | **回合开始** +1 力量 |

形成「开局爆发 vs 逐回合滚雪球」的分工：第 1 回合圣油瓶领先（+2 vs +1），第 2 回合持平，第 3 回合起护符反超。长局护符更好，短局圣油瓶更好，两者都有取用理由。

> ⚠️ 这是程序为消除「严格上位」做的定位调整，**数值/时点以策划追认为准**。

## 三、压力表重做（玩家指定）

**原效果**：每回合开始，若充能低于 2，获得 1 点充能。
**新效果**：每回合开始，**若充能高于 5，自动平衡到 5**（如 9 → -4 → 5）。

**实现**：新增效果种类 `clampCharge`（`value` = 上限，超过则把充能改为该值并发 `ChargeChanged`，不触发 `onGainCharge`）。validator 同步。

**改动后连带**：压力表不再提供充能来源，炉心充能供给只剩 凹痕线圈 / 齿轮空转 / 超频 / 火花塞 / 焊接。为了不让职业掉出区间，同批把此前为压胜率而削的**凹痕线圈（+1→+2）与超频（3→5，升级 4→6）还原**——压胜率的任务交给「压力表封顶 5」本身完成。

## 四、卡面「黄字与介绍重叠」（玩家指定 + 全量检查）

**原因**：`.cflavor` 之前是**绝对定位**（`bottom: 22px`），长描述会从上方顶穿它。实测重叠：炉渣装甲 23.7px、血锈光环 / 荆棘血痂 12.5px、动能电池 8.1px。

**修复**：
- flavor 改为**正向流**（排在描述之后），从结构上不可能重叠；实测全部卡牌 `descBottom - flavTop = -4.3px`（留 4px 间隙）
- 卡面改为纵向 flex + `padding-bottom: 20px`（给强化槽留位）；插画占位 96 → **82px**、名称/描述间距各收 3px、描述行高 1.65 → 1.55，腾出空间
- flavor 最多两行（`max-height: 27px`）超出裁切
- **卡面本身不设 `overflow: hidden`**——否则会连带裁掉左上角超出卡面的费用角标
