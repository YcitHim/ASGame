## §零 读表说明

| 列             | 含义                                                 |
| ------------- | -------------------------------------------------- |
| **招式**        | 这一条意图「是什么」。蓄力条目已展开成一整条链                            |
| **效果（引擎展开值）** | 逐回合的实际节奏。非蓄力招式写「即时」= 当回合就结算                        |
| **权重**        | **相对权重，不是百分比**。只在「当回合通过条件过滤后的候选」之间按权重抽             |
| **连出上限**      | `maxConsecutive`：同一条意图最多连续出现几次。条件把候选全过滤掉时自动放宽，不会卡死 |
| **出现条件**      | 见下                                                 |

**四种出现条件**：

1. **阶段条件**（`selfHpAtLeast` / `selfHpBelow`）——按**敌人自己**的 HP 百分比切表。Boss 的「第二阶段」就是这么表达的。
2. **节拍技**（`everyTurns: N`）——回合数 `% N == 0` 时**强制顶替**本次抽取（优先级高于权重）。把大招从概率玄学变成玩家数得出来的节拍。
3. **追击**（`playerBuff`）——玩家身上该状态层数不够时，这条不参与抽取（不满足就重抽）。
4. **召唤上限**（`maxSummons`）——场上该召唤物数量达到上限时不再抽中。

**几个通用前提**：

- 敌方**格挡在敌人自己的回合开始时清零**（不是玩家回合）——所以「防御」意图的格挡会完整地挡住你的下一个回合。
- 蓄力链的剩余环节在揭示后**不再随机**，逐回合揭示一环。
- 敌人伤害在**锈蚀难度**下 ×1.1；敌人 HP ×1.2（仅影响上限，取整）。
- 场上最多 **4 个**敌人单位。

> **本版口径**：条目里同时给出「**招式**」与「**效果（引擎展开）**」两列，两列若出现数字不一致，**以「招式」列为准**（甲方 2026-10-08 裁定）。

### 8.3 特殊防御状态（本轮新增）

| 状态     | 效果                                        | 谁用                            |
| ------ | ----------------------------------------- | ----------------------------- |
| **虚化** | 只会受到**技能牌**造成的伤害（攻击牌打上去归零）；持续固定回合数        | 沉钟唱诗长（二阶段切换时，持续 3 回合，仅一次）     |

## §十 全局规则速查

| 规则         | 内容                                                                    |
| ---------- | --------------------------------------------------------------------- |
| **场上上限**   | 最多 4 个敌人单位（`MAX_FIELD_ENEMIES = 4`）；召唤与分裂都会被这个上限截断                    |
| **新单位行动权** | 本回合新召唤 / 新分裂出来的单位**当回合不行动**，下回合起正常                                    |
| **敌方格挡清除** | 在**敌人自己**的回合开始时清零（不是玩家回合）——防御意图的格挡会完整挡住你的下一个回合                        |
| **眩晕抗性**   | 精英 / 首领**首次被眩晕后，本场免疫后续眩晕**。带此抗性者：锈蚀看守、锈钟忏悔者、蚀锁链枷手、圣堂典狱长、唤潮主祭、锈喉、沉钟唱诗长 |
| **免疫断链**   | 仅 **锈喉** 与 **沉钟唱诗长**（`interruptImmune`）                               |
| **转阶段保护**  | 锈喉被**跨过** 50% 的一击吃满，随后获得「临界硬化」（受伤 −99%），**玩家回合结束时消失**（甲方 2026-10-08 修订） |
| **亡语结算顺序** | 单位死亡并完成死亡清理后结算；分裂被场上上限截断                                              |
| **难度倍率**   | 普通：敌人 HP ×1、伤害 ×1；**锈蚀**：敌人 HP ×1.2（取整）、伤害 ×1.1                       |
| **污染阈值**   | 危险线 80（每回合开始 −2 点生命）；满 100 立即反噬 10 点并清零                               |
| **意图可见性**  | 全部意图对玩家可见；被**颠倒**的敌人意图数值随机为原值的 50%~150% 且只显示「?」                       |
