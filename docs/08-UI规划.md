# 08 · UI 规划（0.1 定稿级）

> 上游：docs/06（美术基调）、ADR-007（移动端：**锁定横屏 + 旋转提示**，已拍板方案 A）。
> 配套效果图：`docs/mockups/battle-screen.html`（浏览器直接打开，即本文件的战斗界面基准）。

## 1. 设计原则

1. **克制**：火光、烟尘、粒子上限极低；特效为反馈服务，不为装饰服务
2. **读招清晰**：敌人意图一屏可读，信息层级永远 > 美术表现
3. **打击感是魂味的一半**：伤害数字、屏震、卡牌惯性，0.1 就必须到位
4. **信息分层**：常驻（HP/能量/意图）→ 悬停（卡牌详情/关键词注解）→ 点击（牌堆查看/图鉴）
5. **一切状态可视化**：失控线、污染临界、强化激活态，玩家不该心算任何东西

## 2. 设计令牌（Design Tokens，直接可落 CSS 变量）

### 色彩
| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg-abyss` | `#0D0B09` | 战场底色 |
| `--bg-panel` | `#12100E` | 面板/卡牌底 |
| `--bg-raised` | `#1C1915` | 浮起层（手牌悬停、Tooltip） |
| `--ink-bone` | `#E8E0D0` | 主文字（骨白） |
| `--ink-dim` | `#9A9081` | 次要文字 |
| `--blood` | `#8A2B1F` | 血锈红：HP、卖血、危险 |
| `--blood-hi` | `#C0392B` | 失控线激活/暴击高亮 |
| `--gold` | `#B08D4A` | 圣金：描边、费用、稀有框 |
| `--gold-dim` | `#6E5836` | 暗金分隔线 |
| `--rot` | `#5E7B4C` | 污染绿：污染值、腐蚀系 |
| `--steel` | `#6B7A8C` | 械灰蓝：格挡、机械系 |

### 字体
| 用途 | 字体栈 |
|---|---|
| 标题/卡牌名 | `Cinzel, "Noto Serif SC", "STSong", serif`（哥特衬线） |
| 正文/描述 | `"Noto Serif SC", "STSong", "SimSun", serif` |
| 数值 | `Cinzel, Georgia, serif`（伤害数字要"刻"出来的感觉） |

### 质感
- 描边：`1px solid color-mix(gold 55%)` + 内凹暗边 `inset 0 0 0 1px rgba(0,0,0,.6)` = 蚀刻金属框
- 面板：深色底 + 内阴影做旧；禁用圆角大于 6px（魂系是方的、钝的）
- 阴影只用黑色，不用彩色发光（失控线激活等特例用 `--blood-hi` 微光）

## 3. 界面导航流

```
标题画面 ──→ 地图（线性节点）──→ 战斗 ──→ 奖励三选一 ──→ 地图
   │                            │
   ├── 图鉴（占位）              ├── 锻造祭坛（三选一，复用奖励骨架）
   ├── 设置                     ├── 休息点
   └── 继续远征（读档）          └── 结算（胜/负）
```

0.1 共 7 个界面：标题 / 设置 / 地图 / 战斗 / 奖励 / 祭坛 / 结算。图鉴只占位入口。

## 4. 战斗界面规格（基准画布 1280×720，等比缩放适配）

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏 32px：左·章节/节点进度          右·设置/图鉴/日志    │
├──────────────────────────────────────────────────────────┤
│ 敌人区 ~40%：居中立绘 + 血条(含格挡徽) + Buff行 + 意图标  │
├──────────────────────────────────────────────────────────┤
│ 战场带 ~22%：左·玩家状态板(HP/格挡/Buff) 右·污染仪表     │
├──────────────────────────────────────────────────────────┤
│ 手牌区 ~30%：扇形手牌(居中)                              │
│   左下角：能量球 + 血契指示    右下角：抽牌堆/弃牌堆/结束 │
└──────────────────────────────────────────────────────────┘
```

- **锚点布局**：四区各自锚定，中间留出血量浮动数字的净空
- 多敌人（≤4）在敌人区横向排列，间距自适应；当前目标有金色选中环
- 移动端（ADR-007 方案 A：锁横屏）：沿用同一套锚点布局等比缩放；竖屏显示「请横置设备」遮罩；
  窄屏横屏时手牌区可横向滑动，意图图标常驻敌人头顶

## 5. 卡牌组件规格（170×240，悬停放大 1.12×）

```
┌──────────────┐
│ ◆费 │ 卡图区   │  左上：费用宝石(金) + 血契滴血(红)
│ 图  │ (占位符) │  右上：稀有度角标
├──────────────┤
│ 卡牌名(衬线)   │
│ 类型·关键词行  │  关键词上色：血契=红 充能=蓝 污染=绿
│ 效果描述      │  数值加粗骨白，条件句暗金
└──────────────┘
```

**卡牌状态机**：
| 状态 | 表现 |
|---|---|
| 可打出 | 金边微亮 |
| 费用不足 | 降饱和 40% + 费用宝石变灰 |
| 悬停 | 上浮 46px + 放大 + 显示关键词注解 Tooltip |
| 拖拽瞄准 | 卡牌半透，目标敌人显示受击预览（预估伤害数字） |
| 失控线激活 | `--blood-hi` 红光描边 + 卡面微震（红泪迸发类） |
| 强化附着 | 卡底强化槽点亮对应图标（≤3） |

## 6. 反馈与动效规格（参数冻结，全项目统一）

| 动效 | 参数 |
|---|---|
| 卡牌悬停上浮 | 150ms ease-out |
| 出牌飞行（FLIP） | 250ms cubic-bezier(.2,.8,.3,1) |
| 命中反馈 | 目标闪白 80ms + 屏震 200ms ±6px（设置可关） |
| 伤害数字 | 弹出 120ms 放大→停留→800ms 内上浮淡出；暴击/失控线伤害 ×1.4 倍字号 |
| 多段攻击 | 每段间隔 180ms，数字分别弹出（三连击必须"哒哒哒"） |
| 抽牌 | 从抽牌堆 FLIP 入手牌扇形，每张间隔 60ms |
| 敌人死亡 | 立绘碎裂/下沉 500ms + 余烬 |
| 意图揭示 | 回合开始图标翻入 200ms |
| 污染临界(≥80%) | 仪表呼吸红光 1.2s 循环（唯一的循环强调动画） |
| HP<50% | 屏幕边缘血色渐晕（vignette），常驻至恢复 |

动画队列规则见 docs/02 §6；同组事件并行、组间串行；支持跳过与 2× 倍速。

## 7. 图标体系（0.1 最小集）

- **意图**：攻击(剑) / 多段攻击(剑×n) / 防御(盾) / Debuff(骷髅) / 蓄力(漩涡) / 未知(?)
- **Buff**：力量(拳) / 易伤(裂盾) / 虚弱(断剑) / 再生(新芽) / 污染(毒滴)
- **机制**：血契(血滴) / 充能(齿轮) / 义体槽(插槽)
- **节点**：战斗(交叉剑) / 精英(角盔) / 休息(火堆) / 祭坛(砧) / Boss(颅骨门)

风格：单线蚀刻风 SVG，1.5px 线宽，骨白描边，填充透明——禁止彩色卡通图标。
