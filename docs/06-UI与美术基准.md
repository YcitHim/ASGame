# 06 · UI 与美术基准（0.1 定调）

## 1. 魂系 UI 语言

- **配色**：深灰底 `#12100E` / 骨白文字 `#E8E0D0` / 血锈红 `#8A2B1F` / 圣金描边 `#B08D4A`
- **字体**：标题衬线/哥特感；正文优先小字号可读性
- **质感**：做旧纸张卡片、蚀刻金属边框、缓慢火光/烟尘——**克制**，不滥用粒子
- **反馈（0.1 就要做）**：伤害数字、屏幕震动、卡牌打击感是"魂味"的一半

## 2. 战斗布局（PC 横屏基准）

```
┌───────────────────────────────────────┐
│ 顶部：敌人区（立绘+血条+Buff+意图图标） │
│ 中部：战场（玩家状态/护盾/污染值仪表）  │
│ 底部：手牌区（扇形展开，悬停放大浮起）  │
│ 左下：能量球+血契指示   右下：抽/弃牌堆 │
└───────────────────────────────────────┘
```

- **移动端：ADR-007 已拍板方案 A——锁定横屏 + 旋转提示**，竖屏遮罩提示横置设备。
- 手机横屏：手牌改底部横排可滑动，意图图标缩小常驻敌人头顶；基准画布等比缩放。

## 3. 动画队列（ui/anim-queue）

- 消费核心事件流逐组播放（docs/02 §6）
- 必备能力：跳过单场动画 / 全局倍速 / 设置里可关屏震
- 卡牌移动用 FLIP + transform，目标 60fps

## 4. 0.1 美术策略

- 全部可用**程序化占位图**（色块+图标+字体排版），风格基准先行
- 先定：卡牌框模板、Buff 图标风格、意图图标集（攻击/防御/Debuff/蓄力/未知）
- PixiJS 特效层 0.5 才引入，0.1 不留半成品接口
