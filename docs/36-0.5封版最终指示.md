## 程序执行记录（2026-10-06，T1~T3）

> 依 §三 顺序施工，无暂停点。T4 为真人动作，T5 待 T4 签字后合流。

### T1 · meta 解锁补齐 ✅

- 新遗物 `ember_core`（炉心余烬，onBattleStart once:battle → +3 充能，unlockCondition `engineer_first_clear`，入通用遗物池）+ i18n。
- `bloodrust` → `first_boss_clear`；`immortality` → `no_bloodpact_clear`；`redlineprotocol` → `overload3_clear`。
- `RelicDefinition.unlockCondition` + validator schema 同步；`isContentAvailable()` 统一入池判定（卡奖 / 遗物池 / 事件掉落）。
- `stores/meta` 重写：`{ clearedClasses, unlocked, lastUnlocked }` + 存档槽 `meta`（旧档无槽 = 全默认，不回溯发放）；`evaluateRun(achievements)` 结算四项成就。
- 存档 **SCHEMA_VERSION 5→6**：`RunState` 新增 `unlocked / difficulty / usedBloodpact / overloadCount`，迁移链只补进度档（meta / settings 槽不受污染）。
- 成就埋点在 `stores/battle.dispatch()` 从事件流读取（`CardPlayed.bloodPaid>0` / `Overloaded`），core 不做局外判断；`RunState` 随局快照 `unlocked`，core 不反向依赖 meta。
- 结算页提示复用 §三 文案：`meta.unlock`「锈城记住了你的走法——{name} 已解锁。」，CDP 实测 `#/map` 胜利弹窗正确渲染「血锈光环 / 不朽之躯」。

### T2 · 锈蚀难度 ✅

- `DIFFICULTY_PARAMS`（docs/14 Q20 冻结值）：normal HP×1 / 伤×1 / 遗物 3；rust HP×1.2 / 伤×1.1 / 遗物 2。
- 敌人 HP 倍率在 `createBattleState` 生效；伤害倍率在 `attackModifiers`（仅敌方 actor，反伤/环境伤害不吃）；`BattleState/Draft.difficulty` 全链透传（普通档无修饰进管线 → golden 不变）。
- 精英遗物 `run.relicChoices()` 按难度裁到 2；职业选择页同屏二选一 + 锁定态文案（§三⑩ 原文），选中难度写入 `RunState.difficulty`（入存档）。
- sim：`--difficulty rust`，锈蚀档只摸底不设健康线；sim 口径 = 全解锁快照（与 P5 基线对齐）。
