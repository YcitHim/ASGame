## 一、1.0-A · 遗物系统扩展与「随身遗物」

### 1. 问题诊断
遗物 6 件（P6 后 7 件），精英三选一经常「三件都见过」；职业身份件与通用件混在起始配置里，开局零抉择。

### 2. 遗物分级制（三级，写入数据 `tier` 字段）

| 级 | 定位 | 来源 |
|---|---|---|
| T1 起始级 | 强度温和、效果直观，**开局自选池** | 仅职业选择页「随身遗物」 |
| T2 常规级 | 构筑方向件 | 精英三选一 / 事件 |
| T3 稀有级 | 构筑引擎件，带代价或解锁 | Boss 掉落 / meta 解锁 |

### 3. 随身遗物（开局带一件）

- 职业选择页新增「随身遗物」栏：选完职业后从 **T1 池选 1 件**带入；UI 与难度档位同屏（一局前置抉择收在一页的原则不变）。
- 起始配置改为：**职业身份件（固定 1 件）+ 随身遗物（自选 1 件）**——
  - 血械侍僧身份件：`broken_oil` 破碎圣油瓶（开局力量是它的早期根基）
  - 炉心机士身份件：`dentedcoil` 凹痕线圈
  - 第三职业身份件：1.0-B 定
- 原起始 2 件中的另一件（blood_pump / pressuregauge）下放 T1 池，可被任一职业自选——**跨职业捡遗物是正式机制，不是跑题**（充能/污染是三职业共享表）。

## 二、1.0-B · 第三职业「锈语者」+ 起手卡组重构

### 1. 职业定调
- **名称**：锈语者　**称号**：污染共生 · 把毒喝成药的人
- **对偶句**：侍僧卖血，机士蓄压，**锈语者服毒**。
- **设计支柱**：① 污染从「惩罚表」变成「主资源表」——主动吃污染、住在 50~80 的高危区拿增益；② 把污染「吐」给敌人（新机制：敌人侧「蚀锈」减益）；③ 反噬走钢丝：100 反噬对所有人公平，锈语者的技巧是永远停在 99。

### 2. 引擎前置（程序侧，B 阶段开工先决）
| 新增 | 说明 |
|---|---|
| 敌人侧减益 `corroding`（蚀锈） | 计时型：每回合结束受 N 点伤害，持续 M 回合（减益=回合数口径不变）——「把污染吐给敌人」的载体 |
| 效果 `spendPollution` | 消耗自身污染换效果（仿 spendCharge 三模式：damage / block / draw） |
| 效果 `transferPollution` | 把自身污染按 2:1 转成敌人蚀锈（亏比转移，防止白嫖） |
| 解锁条件管线 | 第三职业解锁 = 血械 + 炉心均通关（meta 槽已有 clearedClasses） |

### 3. 卡池与起手
- 卡池 24 张（普通 8 / 罕见 10 / 稀有 6），沿用 docs/29 §二⑥ 的设计表格式，B 阶段启动前我出全案（docs/29 同规格）。
- **起手卡组重构（三职业同步）**：从 5+4+1 照镜子改为不对称结构——
  - 血械侍僧：4 攻 3 防 + 放血 + 输血 + 血矢（10 张，多而杂，第一回合就见血）
  - 炉心机士：4 攻 4 防 + 齿轮空转 + 焊接（10 张，均而稳，第一回合就蓄压）
  - 锈语者：3 攻 3 防 + 4 张机制卡（10 张，机制浓度最高，第一回合就服毒）
  - 基础卡保持白板（删牌与升级的价值不动摇，2026-10-06 讨论结论）；「锈蚀」负担卡暂不入起手，B 阶段真人实测后再评。
- 出口门禁：三职业 400 局各落 45~65% + 玩家真人三职业各一局。
