## 3. 难度专项：无脑攻击问题（玩家实测反馈，最高优先级）

### 3.1 现象
真人实测多局：**只出攻击卡即可通过全部关卡**，防御、副线机制均无出场必要。

### 3.2 归因（策划确认）
1. **战斗太短**：玩家基础输出 24 伤/回合（3 能量 × 打击 8），普通战 3~4 回合结束，防御没有时间价值。
2. **威胁太低**：敌人攻击意图仅 4~10 点/回合，全程没有「不防御就会死」的回合，竞速零风险。
3. **集火减压**：双怪战集火秒一后敌方输出减半，最优策略恒定为纯竞速。
4. **模拟器失真**：sim AI 会打防御/技能，53% 胜率掩盖了「真人纯攻击更优」的事实。**教训：此后难度判定以真人实测为准，sim 只作兜底。**

### 3.3 0.1 处理：数值手术（封版前执行，只改 JSON）

原则：**抬攻击威胁，不抬 HP**（HP 会拖长单局，违背 12~15 分钟目标）；精英与 Boss 已验证，一律不动。

| 敌人 | 字段 | 原值 → 新值 |
|---|---|---|
| rust_hound | 攻击（单发） | 7 → **8** |
| rust_hound | 攻击（双段） | 5×2 → **6×2** |
| corroded_swarm | 攻击 | 4 → **5** |
| corroded_swarm | 污染施加 | 2 → **3** |
| polluting_preacher | 攻击 | 6 → **8** |
| riveted_heavy | 攻击 | 10 → **12** |

**验收线（sim 复跑 100 局）**：胜率 45%~60%、平均回合 ≤ 19。
**回退规则**：若胜率 < 45%，所有改动数值回调一半（如 8→7）再复跑一次；仍不达标则全部还原，问题整体移交 0.5。

### 3.4 0.5 头号课题：决策密度（登记，不在 0.1 做）
- 敌人设计加入「逼迫回应」招式：预告型高伤单发（15+），逼出格挡/爆发回合。
- 防御端价值锚点：格挡附带收益的卡（如「格挡时获得充能」）。
- 奖励池多样性：非攻击卡的抓取动力（配合 docs/14 Q9 充能+3 / 污染+2）。
- 遭遇池轮换（配合分支地图 docs/14 Q17），铁锈傀儡届时进池。
