# 05 · 工程地基清单（0.1 必须完成）

> 这六项是评审后新增的地基投资，优先级高于"多做几张卡"。

## G1 内容构建期校验
- **在哪**：`tools/content-validator`
- **做什么**：zod/schema 校验全部 data JSON，规则见 docs/04 §4
- **验收**：故意在 JSON 里写错一个 handler 名，构建/校验命令必须报错并指出文件与字段

## G2 存档版本化
- **在哪**：`src/systems/save`
- **做什么**：`version` 字段 + migration 链；localStorage key 带命名空间
- **验收**：手写一份 v0 假存档，能被迁移到当前版本且字段无损

## G3 核心层确定性 lint
- **做什么**：lint 规则——`src/core` 内禁 `Math.random`、`Date.now`、禁 import `src/ui` / `src/systems`
- **验收**：故意违例，CI 红

## G4 调试控制台
- **在哪**：`src/systems/debug`
- **做什么**：战斗内指令——`give card <id>` / `set hp <n>` / `set energy <n>` / `add buff <id> <stacks>` / `goto node <id>` / `seed <n>`；仅开发构建注入
- **验收**：W3 起所有战斗 bug 的复现步骤都用控制台指令描述

## G5 内容热更新
- **做什么**：改 data JSON 后战斗内即时生效（Vite HMR + 数据层重载）
- **验收**：改一张卡的伤害数字，不刷新页面看到新数值

## G6 无头模拟器
- **在哪**：`tools/headless-sim`
- **做什么**：纯 Node 跑核心层 + 一个最简启发式 AI（能出牌就出、优先攻击），批量跑 N 局输出报表：胜率、平均回合、伤害分布、卡牌抓用率
- **验收**：W5 结束前能跑通「100 局线性地图」并产出报表；数值崩坏在 0.1 暴露而非 0.5

## CI 最小流水线（W1 搭好）

```
lint（含 G3）→ content-validator（G1）→ vitest 单测 → golden replay 重放
```

全部绿才允许合并。
