## §一 净化事件 → **选 (A)：认了「净化 = 净化污染」**

docs/46 §5.3 的原表述「事件移除全部诅咒/灼烧」与九相铁律「**任何状态都活不过一场战斗**」直接冲突——事件在战斗之外，而诅咒/灼烧只活在战斗之内。这是**我写 docs/46 时的设计疏漏**，认。原表述修正为：

> 事件：act2 事件批里给 1 个「净化」向事件——**净化对象是污染**（本作的局外「诅咒资源」），已落地为「净罪浅池」三选项，语义自洽、零新机制。

**(B)/(C) 一并否掉，理由是同一个**：灼烧的上限在战斗结束时就自动恢复了（docs/46 §3.9 软裁决），跨战斗去「清除诅咒/灼烧」**没有对象**——(B) 的 battleBlessing 和 (C) 的 T2 遗物都是为一个不存在的问题付新机制的钱（B 还要 SCHEMA +1）。

**但「战斗内净化」这个出口我记在案**：若真人实测反馈「被诅咒压得太死、没有反制手段」，出口走**卡牌位**（某职业的战斗内净化牌），不走事件/遗物。本轮不出，备案于此。

## §三 压力表非炉心白板 → **走 docs/43 既有配套：置灰标注**

不加新的「专属」标签体系，也不改成通用效果——** docs/43 §四 Q4 的配套设计就是为此裁的**：「选择页对机制不合件置灰标注，根治跨职业拿白板」。规格：

| 项 | 规格 |
|---|---|
| 非炉心职业的三选一 | 压力表**照常出现但置灰、不可选**，标注小字「炉心充能件——本职业无充能机制」 |
| 为什么不直接移除 | 置灰可见 = 玩家能读到「这件遗物属于另一个职业的世界观」，比消失更有信息量；且池子过滤逻辑零新增（置灰机制 docs/43 已批） |

### 4.1 顺手修：首遇提示与当前动作错位（CDP 抓出来的）

docs/42 的「挑一张牌」提示原先挂在 `RewardView` 的 `onMounted`（只要节点是普通战斗就弹）。首胜三选一上线后，这一步玩家**选的是随身遗物不是卡**，提示文案对不上动作。

改法：提示改为**只在真正进到卡牌三选一那一步**触发（`showPickTip()`，由 `takeCompanion` 与新增的 `skipCompanion` 调用；`onMounted` 里只在没走随身遗物分支时直接触发）。CDP 复验：首胜三选一屏无提示（`reports/relic-unfit.png`），点完遗物 → 卡牌三选一才弹（`reports/card-step.png`）；单测同步加一例。

### 5. 偏差登记与追问

1. **docs/43 与 docs/50 的"禁不禁选"冲突**：docs/43 §2.4 写的是「不隐藏、**不禁止选**（头铁玩家自由），但绝无踩坑不知情」，docs/50 §三 写的是「照常出现但置灰、**不可选**」。本批按**较晚的 docs/50** 实现为不可选，并把同一条规则一并套在**血泵**上（`onSell` 对非血械同样是白板，docs/43 §2.4 原文点名过它）。请确认：血泵在首胜三选一里是否也该不可选——见第八批 §一。
2. **`sim:companions` 的 N/A 只钉了压力表**：血泵的"跨职业白板"性质同一批 UI 已经拦住了，但它的 sim 数字仍照常进三职业的绝对线计算。若按同一口径，血泵在非血械行也应标 N/A——请裁（第八批 §一）。
3. **压力表在 T1 池里仍占一个名额**：非炉心玩家的三选一照常出现压力表，只是不可选，实际可选项可能只剩 2 个（极端情况 1 个或 0 个）。若策划希望"池子里直接剔除、另补一件通用件进来"，那是另一套池子逻辑，请裁（第八批 §一）。
