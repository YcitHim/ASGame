## §二 转地图系统（引擎规格）

### 2.1 RunState 变更

新增一个字段，其余全部复用：

```ts
/** 当前幕下标：0 = 锈蚀回廊，1 = 沉没圣堂（docs/40） */
readonly actIndex: number;   // createRunState 默认 0
```

**存档**：SCHEMA_VERSION 8 → **9**。迁移规则：
- 进行中旧档（act1 未通关）：`actIndex = 0`，照常继续；
- act1 已通关的旧档：标记为**已完结 legacy 局**，不提供「继续远征」入口（不迁移成可进第二幕的档——旧档没有第二幕的随机流上下文，强行续档会破坏 replay 一致性）。

### 2.2 过幕流程（伪代码即规格）

```
isRunComplete(run, act1) == true        // 击败锈喉、走完 l7
  → 战斗结算照常（卡奖三选一 + Boss T3 遗物槽）
  → 进入幕间过场画面（IntermissionView）：
      1. 全屏过场文案（i18n: intermission.act1_to_act2，文案见 §2.5）
      2. 圣堂馈赠三选一（§2.3）——必须选，不可跳过
  → applyIntermission(run):
      actIndex = 1
      layerIndex = 0; picked = []; cleared = []
      hp = min(maxHp, hp + floor(maxHp × 0.25))     // 回复 25%，向下取整，最少 1
      pollution = 0                                  // 污染清零（peak 保留用于成就）
      // 充能/Buff 本就不存于 RunState，无需处理
      // 牌组/遗物/强化/使用记录（usedBloodpact 等成就字段）原样保留
  → 渲染第二幕地图（§三）
```

**第二幕战败**：本局作废，与一幕一致；结算页「最深层」字段记 `act: 2, layer: n`（新增统计字段，存档 v9 一并加）。
**第二幕通关（v1.1 即整局胜利）**：结算页标注「沉没圣堂已净」，成就 +1（见 §2.6）。

### 2.3 圣堂馈赠（三选一，必答）

| 选项 | 效果 | 实现 |
|---|---|---|
| A 圣水洗礼 | 回复 maxHp 的 50%（floor） | healRun 复用 |
| B 默记祷文 | 免费升级 1 张牌 | 复用休息点升级 UI，选完返回过场 |
| C 圣堂锻核 | 从**幕专属强化池**（§七 4 枚 + 通用池）随机抽 1 枚，走正常附着流程 | rollEnhancementChoices 管线复用 |

**边界**：若全卡组强化槽全满（每卡 3 槽皆满），C 项**置灰**，A/B 必选其一——不允许出现「三项皆不可选」。

### 2.4 随机流与种子（replay 一致性）

| 用途 | 规格 |

## §三 act2.json 逐层规格（直接可抄）

```json
{
  "id": "act2",
  "i18n": "act.sunken_sanctum",
  "classes": ["bloodwright", "engineer", "rustspeaker"],
  "weights": { "battle": 50, "elite": 0, "rest": 0, "altar": 25, "event": 25 },
  "layers": [
    { "id": "l0", "width": 1, "kinds": ["battle"], "encounters": "池A" },
    { "id": "l1", "width": 3, "kinds": ["battle", "altar", "event"], "encounters": "池A", "events": "圣堂事件池" },
    { "id": "l2", "width": 1, "kinds": ["battle"], "encounters": "池B" },
    { "id": "l3", "width": 1, "kinds": ["elite"], "elitePool": ["sanctum_jailer", "tidecaller"] },
    { "id": "l4", "width": 1, "kinds": ["rest"] },
    { "id": "l5", "width": 3, "kinds": ["battle", "altar", "event"], "encounters": "池C", "events": "圣堂事件池" },
    { "id": "l6", "width": 1, "kinds": ["elite"], "elitePool": ["sanctum_jailer", "tidecaller"] },
    { "id": "l7", "width": 1, "kinds": ["boss"], "enemies": ["drowned_choirmaster"] }
  ]
}
```

**与 act1 的差异即设计意图**：双精英（l3/l6）夹一个必经休息点（l4）——第二幕的节奏是「高压 - 喘息 - 更高压」；祭坛不保证必出（期望约 1 个），由事件「沉钟敲响」（§八 E4）兜底强化获取。

**需要引擎小改的两处**（都写明规则，程序不用问）：
1. **elitePool**：elite 层支持池。抽取规则：l3 用 `new Rng(run.seed ^ 0xE117E3).stream("map")` 池抽一；**l6 抽取时排除 l3 已抽中的那只**（同幕双精英不重复）。
2. **分支层 kinds 不含 rest/elite**：act2.weights 里 elite/rest 为 0 是刻意的——分支只出现 battle/altar/event，高压节点全部固定，保证每局的难度骨架一致。

## §五 召唤机制规则边界（引擎小改，全部定死）

1. **新 intent kind**：`"summon"`，参数 `{ "enemyId": "...", "count": 1 }`。count 本幕恒为 1，字段留着为 v1.2。
2. **场上敌人上限 4**（含召唤物）。满员时 summon 意图视为**不可用**，按该敌人剩余意图权重重抽一次；若重抽仍不可用（极端情况全部不可用），fallback 为 `attack` 最低档值。
3. **可抽中条件**：意图条目可加 `maxSummons`（如 rust_pilgrim 的 acolyte <2）——实现为「抽中后校验，不满足按 §2 重抽」，不做成 condition 系统新类型（避免 D-3 式提前抽象）。
4. **召唤物入场**：出现在召唤者右侧空位；**入场当回合不行动**，下一回合起走自己的意图循环（吃标准意图系统，无特例）。
5. **殉爆规则**：召唤者死亡时，**其召唤物立即殉爆**（不触发召唤物自身 onDeath——防止 tide_swarm 连锁生虫）。理由：防「主人死了还要清杂鱼」的垃圾时间。战斗胜利判定不变（全灭）。
6. **onDeath 连锁**：召唤物自身的 onDeath 正常触发（tide_mite 无 onDeath，无连锁风险）；tide_swarm 被殉爆规则排除在外（它是召唤者时按 §5，是被召唤者时无此情形）。
7. **sim / 多目标**：复用现有多敌战斗管线；sim AI 目标选择沿用「集火最低 HP」既有策略，v1.1 不为召唤物改 AI（登记观察项）。
8. **断链**：召唤物若为蓄力型（本幕没有），吃 1.0-C 断链规则；本幕无特例。

## §九 预答 FAQ（程序可能问的，全部先答）

1. **act2 敌人美术？** 沿用第一幕惯例：占位图形 + 色块，主题色偏青蓝（水）以区别于第一幕的赭红（锈）。
2. **图鉴怎么分组？** 按幕分组：回廊 / 圣堂；召唤物（tide_mite / rust_acolyte）单列条目，见过即解锁。
3. **第二幕有新卡吗？** 没有。卡池沿用三职业既有池，v1.1 不加职业卡（控制平衡面）。
4. **第一幕敌人/事件会出现在第二幕吗？** 不会。主题隔离；混合精锐池是 v1.2 第三幕的事。
5. **双幕连打时长超了怎么办？** 目标 20~25 分钟。sim 复跑若平均回合数 > 一幕 ×1.9，先压第二幕小怪 HP（每次 -10%，bell_warden 最后动），不动节点结构。
6. **圣堂馈赠 C 项全满槽？** 置灰，A/B 二选一（§2.3 已写）。
7. **幕间 HP 回复 25% 取整？** floor，最少 1。
8. **充能过幕？** RunState 本就不存充能（战斗内资源），无需处理——同污染清零的口径已在 §2.2 写明。
9. **旧存档想玩第二幕？** 开新局。迁移规则见 §2.1，不提供旧档续幕。
10. **召唤物吃力量/易伤吗？** 吃——它是标准敌人单位，走标准管线，无特例。
11. **唤潮主祭满场时AI会不会死循环抽 summon？** 不会——§五-2 重抽一次 + fallback 已写明。
12. **锈蚀难度参数过幕变化吗？** 不变，全幕生效（docs/39 已定）。
13. **成就「圣堂不湿身」馈赠回血算不算？** 不算（§2.6 已写明：进过场时即满血才算）。
14. **第二幕 Boss 战输了，从哪重来？** 本局作废（与一幕一致）——v1.1 不做幕内检查点；该议题归档 v1.2 再评（三幕 35 分钟时才值得讨论）。
