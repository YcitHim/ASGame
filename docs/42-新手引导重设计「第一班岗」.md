## §一 诊断：现在的教学为什么教不会人

对照实现（`src/ui/tutorial.ts`、`src/stores/tutorial.ts`、`src/ui/views/TutorialView.vue`、`src/ui/first-tips.ts`），七个病灶：

| # | 病灶 | 证据 | 后果 |
|---|---|---|---|
| D1 | **职业机制零覆盖** | ~~邀请挂在首页~~（勘误：邀请在职业选择页，卡组兜底分支只是预览；见 docs/43 附）——真正的问题是三课脚本全是通用战斗，血契/充能/污染一个都没教 | 反馈 1（卖血看不懂）恰恰是职业机制问题，教学对它零覆盖 |
| D2 | **判定过粗：教的是机械点击，不是理解** | `ui/tutorial.ts:9-11` 的完成条件只有 `playType(attack/skill)` 和 `endTurn` 两种 | 点任何一张攻击牌都算「做对」；「没能量了就结束回合」不校验能量是否真的用完——玩家可以带着 3 点能量结束回合照样过关，学完依然不懂能量 |
| D3 | **只教战斗，不教游戏循环** | 三场脚本全是战斗；弃牌/奖励三选一/地图路线/休息点/强化/遗物/图鉴全部缺席 | 反馈 3（为什么自动弃牌）、反馈 9（遗物怎么选）正是循环层问题——玩家打完三课依然不知道「这一局我要干什么」 |
| D4 | **只告诉点哪，不告诉为什么** | 所有 hint 是命令式一句话（「点一张高亮的攻击牌」） | 玩家会操作但不知道为什么这么做，换个场面就不会了 |
| D5 | **没有安全网** | 教学战斗走真实结算，无免死、无纠错 | 新手在第二课被虫群打死，比不教更挫败——「教学关都能死」是口碑杀手 |
| D6 | **没有小结与结业** | 三场打完只有一句「走完了」（`TutorialView.vue:74`） | 学完的成就感、知识点的固化、接下来去哪——全都没有 |
| D7 | **首遇提示覆盖太薄** | `first-tips.ts` 仅 5 条（弃牌/血契/保留/蓄力/能量） | 循环层全靠玩家自摸，与 D3 互为因果 |

**一句话总结**：现在的教学是「三场带提示的战斗」，而新手需要的是「一段被陪着走完的旅程」——他要知道的不只是怎么打牌，而是**这游戏从头到尾在玩什么**。

## §二 重设计总纲：「第一班岗」

把「三场孤立教学战」改为「**一段 10~12 分钟、被全程旁白的引导式微型远征**」。名字：「第一班岗」——你是新报到的守夜人，老班长带你值第一班。

**三条设计原则**：

1. **在真实循环里教，不在隔离沙盘里教**——微型远征有地图、有奖励、有休息点，只是每一步都被旁白。玩家学到的每个概念都长在它真正出现的位置上。
2. **先建心智模型，再教操作**——每个知识点 = 一句「为什么」+ 一句「怎么做」。操作可以忘，模型留下就够。
3. **允许犯错，绝不允许迷茫**——打错有纠正，死了有兜底，任何时刻玩家都清楚「现在该干嘛」。

## §三 流程全案

### 3.0 时序修正（治 D1）

```
选职业（首次选择某职业时）
  → 「第一次带这班上岗？老班长可以陪你走一趟。」（可跳过，设置页可重进）
  → 「第一班岗」微型远征（固定使用该职业与起始卡组）
  → 结业 → 无缝衔接正式远征第一层
```

- 邀请时机从「首页」挪到「选完职业」——教学用的牌、教的职业机制，与玩家即将开的一局**完全一致**。
- meta 记录改为**按职业**记录：`tutorialDone: { bloodwright?, engineer?, rustspeaker? }`——换职业第一次玩时，第三课（职业机制段）单独补教，前两课可跳过。
- 解锁中的职业（锈语者）在解锁后首次选择时同样触发。

### 3.1 全程结构图

```
序章 30s ──→ 课1 出牌与回合循环 ──→ 幕间A 第一次奖励 ──→ 课2 意图与生存
                                                              │
结业清单 ←── 课3 蓄力与职业机制 ←── 幕间B 地图与休息 ←────────┘
   │
   └→ 正式远征第一层（首遇提示作为安全网继续兜底）
```

### 3.2 序章 · 你要干什么（30 秒，一屏）

不进战斗，一页图文三行话：

> 你要从这层爬到顶，干掉守顶的那个大家伙。
> 路上会死。死了就从头再来——但图鉴、解锁、和你的记性会留下来。
> 这一班我陪你走。

**心智模型先行**：先回答「这游戏目标是什么、死了会怎样」，再谈操作。这是现在完全缺失的一块。

### 3.3 课 1 · 出牌与回合循环（对手：锈犬 ×1，低压木桩）

| 步骤 | 旁白（为什么 + 怎么做） | 完成判定（治 D2） |
|---|---|---|
| 1 | 「手牌是你的动作，能量是你的力气。左上角数字是费用——先打一张攻击牌试试。」 | 打出 attack（宽判定，第一步只求破冰） |
| 2 | 「能量用不完不会留到下回合，别省。把剩下的力气花完。」 | **能量 = 0** 或手牌无可打牌（严判定） |
| 3 | 「没力气了就结束回合。注意看——没打的牌不会留着。」 | 结束回合，且**确实触发弃牌阶段**（旁白在弃牌动画播放时同步指出弃牌堆位置） |
| 4 | 「牌堆抽空了会把弃牌洗回去——所以好牌烂牌都会再见，出牌不用心疼。」 | 自由行动，击杀锈犬 |

**关键改动**：弃牌机制不在 tips 里干讲，而是在玩家**第一次亲眼看到手牌飞进弃牌堆的瞬间**由旁白点破——反馈 3 的根治思路是「在现象发生的现场解释现象」。

### 3.4 幕间 A · 第一次奖励（三选一怎么选）

战斗结算画面旁白：

- 「打赢一场，挑一张牌进卡组。卡组是你这一局的资产，会一直跟着你。」
- 「新手口诀：**不知道选什么，就选能马上用的**——费用低、效果直白的牌。」
- 三张候选固定为 1 攻 1 防 1 花活（种子固定），旁白逐张一句话点评——**教的是选牌的思考方式，不是替玩家选**。

### 3.5 课 2 · 意图与生存（对手：腐蚀虫群，固定种子开局必攻）

| 步骤 | 旁白 | 完成判定 |
|---|---|---|
| 1 | 「敌人头顶的图标是它下回合的预告：剑 = 要揍你，数字 = 揍多狠。看一眼再出牌。」 | 结束回合（观察步，宽判定） |
| 2 | 「它预告了 6 点——打防御牌把格挡叠起来。格挡就是临时的血。」 | **格挡 > 0 时结束回合**（严判定） |
| 3 | 「看，格挡吃掉了伤害。但格挡每回合开始清零，所以要在挨打前叠，别提前浪费。」 | 敌方攻击被格挡部分吸收 |
| 4 | 「有的牌写着「保留」——它能留在手里等下回合，别的好牌可留不住。留着关键牌等关键回合。」 | 自由行动，击杀虫群 |

### 3.6 幕间 B · 地图与休息（微型地图一屏：3 个节点）

- 「远征是在地图上选路。图标念一遍：剑 = 打小怪，骷髅 = 精英（难但赏好），篝火 = 休息，问号 = 遇事，顶上是 Boss。」
- 「篝火能回血或升级一张牌。血还够就升级，快死了就回血——**活着到 Boss 面前比什么流派都重要**。」
- 玩家在微型地图上实际点选一次路线（二选一，无对错），旁白不干预选择只解释后果。

### 3.7 课 3 · 蓄力与你的职业（对手：铆接重卫，蓄力演示木桩）

**前半·蓄力（三职业通用）**：

| 步骤 | 旁白 | 完成判定 |
|---|---|---|
| 1 | 「这个大家伙在蓄力——它架起格挡，头顶写着几回合后释放多少伤害。它在攒一记狠的。」 | 结束回合 |
| 2 | 「红框「即将承受 X 伤害」就是那一下。这一回合：**先活着**。把格挡叠够。」 | 敌方释放回合玩家存活 |
| 3 | 「顶住了？它刚放完大招是最虚的时候——把所有输出砸回去。」 | 击杀重卫 |

**后半·职业机制（按所选职业换脚本，治 D1）**：

| 职业 | 教学内容 | 旁白要点 |
|---|---|---|
| 血械侍僧 | 血契实战：打一张 `transfusion` | 「你的牌先要血。别慌——牌面下方「净 +4 HP」是算完账的结果。卖血是你的战斗方式，不是自残。」 |
| 炉心机士 | 充能实战：打两张充能牌再释放 | 「充能给你所有攻击加码，攒着放大的。但别贪——超过 10 会过载炸自己。」 |
| 锈语者 | 污染实战：吃污染换效果 | 「污染是毒药也是弹药。盯着它，满 100 会反噬。在毒里跳舞，别被毒淹了。」 |

判定统一为：打出指定机制牌 → 旁白确认机制生效（血扣了又回 / 充能数字跳动 / 污染上涨）。

### 3.8 结业清单（治 D6）

一页清单，逐条打勾动画，每条可点开挂回看：

```
✓ 出牌花能量，能量不隔夜          ✓ 没打的牌进弃牌堆，会洗回来
✓ 敌人头顶是预告，先看再动        ✓ 格挡是临时的血，挨打前叠
✓ 打赢挑牌，卡组跟着你走          ✓ 地图选路，篝火续命
✓ 红框「即将承受」= 先保命         ✓ 你的职业绝活（血契/充能/污染）
```

收尾文案：「这班你值完了。往后的岗，自己站——忘了就翻图鉴（右上角），或者从设置里再叫我。」
→ 直接发进正式远征第一层，**不回首页面**（连贯感：教学是这一局的序章，不是局外的附录）。

## §四 安全网与纠错（治 D5）

| 机制 | 规格 |
|---|---|
| **免死** | 教学战斗中玩家 HP 降到 ≤1 时：本次伤害截断到 HP=1，旁白「这一下本该放倒你——记住，格挡要在挨打前叠」，战斗继续。全程只触发一次，第二次仍至 ≤1 则旁白后直接补满并快进该场（不卡关） |
| **纠错不锁死** | 严判定步骤玩家做错（如该叠格挡却打了攻击）：旁白一句纠正 + 高亮目标，**不重开不惩罚**，等玩家自己做对 |
| **随时出口** | 右上角「跳过教学」常驻；跳过 = 中断引导直接进正式远征，无惩罚无确认弹窗 |
| **回放** | 图鉴新增「第一班岗」页：八条结业清单 + 三课脚本可随时重看、重进 |

## §六 技术约束与改动面（给程序的边界）

1. **不动核心层**：所有旁白/判定/免死都走事件订阅 + UI 层状态机（沿用 `stores/tutorial.ts` 模式），免死用修饰管线的一枚教学专属 modifier 实现，不碰结算。
2. **判定模型升级**：`TutorialStepDone` 从 2 种扩为 6 种——`playType` / `endTurn` / `energyEmpty` / `hasBlock` / `survivedRelease` / `freeplay(击杀目标)`；每步可声明 `strict: boolean`。
3. **固定种子**：三场敌人种子沿用现值并复验意图序列（课 2 要求开局必攻、课 3 要求蓄力节奏与脚本台词吻合）。
4. **meta 存档**：`tutorialDone` 改按职业记录，SCHEMA_VERSION +1，旧档迁移为全 false（等于重新邀请一次，可接受）。
5. **规模控制红线**：微型远征 = 3 战 + 2 幕间 + 序章 + 结业，**不再加内容**；进阶机制（强化附着、事件抉择细节）依然交给首遇提示与玩家社区。

## 程序执行记录 · 「第一班岗」重设计落地（2026-10-07）

### 一、架构（按 §三/§四/§五/§六 全部实施）

| 章 | 形态 | 实现 |
|---|---|---|
| 序章 | 纯文本屏 | `screen` 章：三行台词 + 「上岗」 |
| 课 1 | 战斗 | 锈蚀猎犬（种子 7）· 4 步：打攻击牌 → 花光能量（严）→ 结束回合看弃牌 → 清场 |
| 幕间 A | 奖励三选一 | 按职业固定 1 攻 / 1 防 / 1 花活 + 逐张点评；拿走即进教学卡组 |
| 课 2 | 战斗 | 蚀肉锈虫群（种子 1，开局必攻）· 4 步：看意图 → 格挡后结束回合（严）→ 扛过攻击 → 清场 |
| 幕间 B | 地图与篝火 | 3 图标讲解 + 二选一选路；选篝火进「回血 / 升级」二选一，**真的改教学局的 HP 与卡组** |
| 课 3 | 战斗 + 职业机制 | 铆装重卫（种子 10，开局蓄力）· 通用 3 步（看蓄力 → 扛过释放 → 清场），**每个职业再追加机制段**（血械 transfusion / 炉心 sparkplug→chargedhammer / 锈语者 toxsip→rustspit） |
| 结业 | 清单屏 | 八条打勾 + 收尾文案 + 「开始远征」直达正式第一层（不回首页） |

- **微型远征状态**：教学有自己的 `hp / maxHp / deck`，战斗之间带过去（幕间 B 的篝火才有意义）。
- **判定模型**：`playType / playCardId / energyEmpty / spendAll / endTurn / blockEndTurn / survivedRelease / killAll` 共 **8 种**（原计划 6 种），每条可 `strict`；严判定失败只在提示带里给一句纠错，**不推进、不惩罚、不重开**。
- **免死**：`BattleState.safetyFloor` + `SafetyNet` 事件。第一次把致命伤截断在 HP=1 并旁白纠正；第二次补满并继续，保证不卡关。
- **按职业记录**：`meta.tutorialOffered / tutorialDone` 改为职业数组，`SCHEMA_VERSION 10 → 11`（旧档重置为"没被问过"，按你在 §六.4 的裁定）。已完成过任一职业的第一班岗后，**换职业只补第三课的机制段**。
- **首遇提示 5 → 12 条**（§五全表）；教学里讲过的条目在正式局首次再遇时**直接标记已读不再弹**（`triggerUnlessTaught`），教学与提示互为补位而不是复读。
- **图鉴新增「第一班岗」页**：八条结业清单 + 七章脚本 + 「重进第一班岗」。

### 二、程序侧偏差登记（按 §六 边界，需要你追认）

1. **§一 D1 的前提不成立**：邀请本来就挂在**职业选择页**（点头像选职业那一刻），不是首页；`TutorialView` 那句「未选职业：将使用默认职业」只是卡组预览的兜底分支，真实流程里 `choose()` 已先开局，**教学卡组一直是玩家所选职业的**。D1 另一半（三职业核心机制零覆盖）完全成立，已按 §三.7 补齐。
2. **免死不能用修饰管线实现**：修饰管线只缩放伤害**数值**，而"这一下会不会把玩家打死"取决于**吸收格挡后的剩余 HP**。硬塞进管线会得到错误的结算。改为在 `dealDamage` 里加一个明确的安全阀（`safetyFloor`，默认 `undefined` = 关闭），并向事件流发 `SafetyNet`——**正常局与 golden 回放完全不受影响**（已用 2 条对照用例锁住）。

## 程序执行记录 · 试玩热修：教学第二步卡死（2026-10-07）

### 玩家报的现象
「一直提示能量不隔夜，不会切换，也没有引导」——**卡在第一课第 2 步出不来**。

### 根因（我的实现与你的原文不一致）
你在 §三.3 step 2 写的是「**能量 = 0 或手牌无可打牌**（严判定）」，是**两个**出口。我实现成了 energyEmpty——**只有「能量恰好为 0」一个出口**，而且只在「打出牌之后」判定，结束回合时对这一步**什么也不做**（连纠正都没有）。于是：

- 剩 1 点能量、手里只剩 2 费牌 → 永远打不到 0 → **任何操作都不推进**；
- 结束回合也不推进、也不提示 → 玩家看到的正是「同一行提示 + 没引导」。

### 同一族还有两处（自查发现，一并修）

| 处 | 问题 | 修法 |
|---|---|---|
| 课 2 step 3 | 我把目标写成了 survivedRelease，可**蚀肉锈虫群根本没有蓄力**——这个条件永远不成立 | 新增判定 **blockedHit**（格挡真的替玩家吃掉了一部分伤害），并接 DamageDealt.blocked > 0 |
| 课 2 step 2 | 严判定要求「带着格挡结束回合」，可**起手 5 张里有没有防御牌是发牌运气**——运气不好就卡死 | 新增 **classGrant**：这一步按职业保底发一张格挡牌（defend / brassguard / scrapguard） |

### 修法
1. step 2 的目标改回你原文的宽口径 **spendAll**：打牌打到 0，**或**结束回合时能量为 0 / 手里已无打得起的牌，两条都算过。
2. **严判定没做到时，一定要给一句人话**（step.correct，缺省用「这一步还没做完——<怎么做>」）——从机制上消灭「干瞪眼」。
3. 机制课同理：二段机制牌（充能锤 / 锈唾）也在自己那一步补发一次，避免玩家在上一步先把牌打了导致下一步无牌可打。

## 程序执行记录 · 教学系统重构「速成版」（2026-10-07，甲方口头指令）
