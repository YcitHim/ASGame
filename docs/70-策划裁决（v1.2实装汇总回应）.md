## §二 逐项裁决与理由

### 2.1 骨架层：追认「必现」，门禁不动

docs/48 的宽度/配额门禁是地图生成数学的护栏，为一个**尚未经真人验证的节奏假设**动地基，不值。「必现一个精英/篝火」已经把 docs/66 要的「有峰、能喘」放进了地图——玩家能不能绕过去是选择问题，不是节奏问题（能绕 = 给怂的留活路，反而多一个决策）。

「双精英同层」**不做**。三幕的强度表达走 statMult 和遭遇编排，不靠违反生成规则。

**复盘条款**：封版前真人实测若反馈「读不出峰/喘」，单独开题。届时首选方案 = 放宽「该层节点全同 kind」（只动宽度一条），**仍不碰**同层精英 ≤1。

### 2.2 三幕事件池：补 3 个事件，不开豁免、不接受回落

三选一里选 **① 补内容**。理由：

- 「事件池 ≥6」是内容质量护栏（docs/54 §六），为 3 个事件开豁免 = 为偷懒改规矩，口子一开收不回；
- 「回落全局池」不可接受——八轴 ⑤（感知层）的核心就是「三幕只讲锻炉的故事」，抽到一幕的血当铺会直接把幕氛围戳破；
- 补 3 个是策划的本职，已在 §三 给全（设计 + JSON + 文案），程序照抄落数据，零引擎改动。

凑齐 6 个后按一二幕同构方式挂载：**act3.json 的 l1 / l5 各加 `events` 数组**（6 个 id 全列），`inheritedPool` 会自动惠及其他层（已核实 `core/map/index.ts` 的继承逻辑与 act1/act2 的挂法一致）。

### 2.3 锈心低语：接受换设计

50% T2 遗物 / 50% 污染 +10。戏剧性没丢（反而更贴「炉底还压着几件」的文案），省一次 SCHEMA_VERSION 变更，值。**原「下一场开场虚弱」设计永久废弃**，不进 backlog——为一个事件动存档结构的口子以后也不开。

### 2.4 备选遗物两件：保留

淬火怀表 / 赌徒齿轮实装保留，**遗物总数登记为 37**（docs/64 的 35 + 2）。新增的两个原语（`onDamaged` 受击钩子 / `chance` 概率分支）是通用件，`chance` 以后做赌博类卡牌也能用，引擎面扩大得值。

### 2.5 炉心余温：按 spendCharge，口径锁定

**是**。策划口径一次写死：**「蓄力释放牌」= 把充能花出去换效果的牌（`spendCharge`）**，不是「有充能成本」的牌。chargeCost>0 的两张技能牌（泄压阀/齿轮传动）是充能的「搬运工」，不是「释放」，以后所有同类文案统一这个口径。

### 2.6 炉前督军：首版数值保留

280 HP / 双环蓄力释放 24 / 固定力量 2 作 v1.2 首版。sim 0.0% 只当「AI 打不过三幕」的方向哨兵（docs/49 口径），**终审 = 封版前真人实测**，与特性补丁的实测排在一起做。

### 2.7 特性平衡补丁：六条全认，附一条文案口径

A1/A2/B2（玻璃大炮）/ N1/N2/T1（铁皮王八）**追认**。两盘 golden 重录、9 条断言更新、2 条新行为锁，都符合随改随录的老规矩。

**补充口径（程序收尾时核对）**：T1 混合充能是「**另分**」不是「**挪走**」——充能仍然**全量**折算格挡，攻击牌的 ⌊充能/2⌋ 加伤是额外红利。请检查特性选择界面与相关 i18n：如果文案写成「充能一半给格挡一半给攻击」就是错的，正确表述是「充能全量转化为格挡；你的攻击牌额外获得 ⌊充能/2⌋ 点伤害」。文案若没写清，顺手补。

### 2.8 幕标识主题色：后置 v1.2.x

同意后置。最低成本替代已经够用：`node.act3.*` 节点文案 + 幕规则常驻提示条（批已实装）承担了「我在第几幕」的感知。主题色/专属 UI 皮肤记入 backlog，v1.2.x 与无尽回廊一起排。

## §三 新增锻炉事件 ×3（策划定稿，程序照抄）

三个事件**全部使用现有效果积木**（hpPercent / upgradeRandom / gainEnhancement / removeCard / outcomes 权重），零引擎缺口。加上现有 3 个（锻炉洗礼 / 炉渣商人 / 锈心低语）正好 6 个，过 validator「事件池 ≥6」门禁。

设计轴心（6 个事件各占一条轴，互不重叠）：

| 事件 | 决策轴 | 一句话 |
|---|---|---|
| forge_baptism 锻炉洗礼（已有） | 上限 vs 污染 | +8 maxHP 换 +15 污染 |
