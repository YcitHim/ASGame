## 一、需要你拍板（按影响排序）

### Q1 · 设置页的三个音量滑块是空壳（P0 · 信任问题）

- 现状：设置页有「主音量 / 音乐 / 音效」三个可拖动的滑块，但全项目 **0 处音频播放代码**（grep 音频相关关键字只命中设置项自己）。
- 玩家会怎么想：「我调了音量还是没声音」→ 当成 bug。这比没有声音本身更伤信任。
- 三个选项：**(A)** 这版把它们标注「暂未开放」并禁用；**(B)** 直接删掉，等有音频再加；**(C)** 你们给音效预算，我接一个最简音频层（出牌 / 命中 / 回合切换三条 + 一首循环 BGM）。
- 我的建议：**先 (A)**，音频留到 v1.1 一起做。

### Q2 · 教学进度不落盘（P1 · 体验）

- 现状：教学进行中的「第几章第几步 / 教学局 HP / 教学卡组」全在内存里；只有「已读提示」和「已完成职业」落盘（meta）。刷新、关标签、切走再回来 → **教学从头开始**。
- 代价：10 分钟白走，而新手恰恰最可能中途刷新。
- 我的建议：落盘 tutorial 的 chapterIndex / stepIndex / hp / deck，SCHEMA 11 → 12，成本很小。**要不要做？**

### Q3 · 「保留」对两个职业永远不存在

- 现状：全卡池**只有 brace（血械侍僧）**带 retain 关键词。锈语者 / 炉心机士玩家一辈子遇不到「保留」，连 retain 首遇提示对他们也永不触发（提示的触发条件是「卡组里有保留牌」）。
- docs/41 §2.3 专门为「保留 / 维续」做了消歧，但如果只有 1/3 的职业能见到它，这条词条的实际价值有限。
- 三个选项：**(A)** 给另外两个职业各补一张保留牌（需要你出卡：名字 / 费用 / 数值 / flavor）；**(B)** 接受「保留是血械的专属关键词」，把词条改写成血械口径；**(C)** 先不管。
- 我的建议：**(A)** —— 两张牌的成本，远低于让一条机制只对 1/3 玩家可见。

### Q4 · T1 随身遗物的逐件裁决表还没到

- 报告在 docs/program/1.0.x-T1随身遗物强度分布报告（程序侧）.md：8 件 × 3 职业 × 400 局。中位数 44.4%、极差 20.6pp、按「≥ 中位数 70%」表观全达标，**但有三件实际低于本职业的裸装基线**（寻锈杖 / 压力表 / 齿轮币）。
- 除了逐件裁决，还有两条建议请你一并裁：
  1. **血泵心脏是否降级为血械身份件**（血械身上它比第二名高 20pp、比裸装高 32pp，其余七件几乎等于裸装）；
  2. **「任何 T1 件在任何职业上都不得低于该职业裸装基线」是否立为绝对线**（相对中位数的尺子会被整池弱件拉平）。

### Q5 · 第二幕小怪 HP 要不要按 docs/40 §九-5 压

- 双幕 400 局 bloodwright AI 胜率 **1.8%**（参考线 35~55%）；过精英后 P50 只剩 18 HP（设计意图 ≥25）。
- docs/40 §九-5 已预授权我压第二幕小怪 HP（bell_warden 最后动），但我一直没动，等你一句话。

### Q6 · 成就「引路人」的判定口径

- 现状：完成**任一职业**的第一班岗即解锁。
- 速成版已经**取消「按职业补教机制课」**（职业机制课本身被砍了），所以按职业记录现在只剩「图鉴里显示走了几个职业」这一层信息。
