## 2. 相对 1.0 的新增玩法

### 2.1 第二幕「沉没圣堂」
1. **幕间过渡（docs/39 §三 / docs/40 §2.2）**：击败第一幕 Boss 锈喉后进入幕间，当前 HP 回复上限 **25%**、污染与充能清零，随后在**圣堂馈赠三选一**中定向补强：① 回复 50% HP　② 免费升级 1 张牌　③ 第二幕专属强化随机一枚。
2. **第二幕地图**：`act2` 10 层，中段分支，精英密度提高；节点文案独立（`node.act2.*`）。
3. **第二幕敌人 11 只 + Boss**：`drowned_crawler / choir_echo / tide_swarm / tide_mite / bell_warden / tidecaller / deep_diver / silent_matron / sanctum_jailer / barnacle_host / rust_pilgrim` + Boss `drowned_choirmaster`。
4. **第二幕专属强化池 4 枚**：`sanctum_quench / choir_reverb / sunk_cost / abyssal_hush`，与幕间馈赠 ③ 挂钩。

### 2.2 九相九态与敌方挂载（docs/46 / docs/47）
5. **诅咒四机制转正**（docs/49 Phase 2a）：冰缓（手牌 +1 费 / 敌方造伤 ×0.8）、颠倒（手牌费用重掷 / 敌方意图 50%~150% 迷雾）、眩晕（整回合不可出牌、仍可结束；精英 Boss 首次免疫）、灼烧（每层每回合 −1 生命上限，战斗结束恢复）。
6. **敌方一怪一诀**（docs/47 M1+M2）：25 只敌人各自带规则（诅咒挂载、蓄力链、亡语、召唤），act1 补两只精英 `rust_bell_penitent` / `chain_flailer`。
7. **分裂亡语解锁**（docs/47 M3）：`onDeathSplit` 转正，锈疱鼓腹兽 / 藤壶寄居者死后分裂，自指与链式分裂由 validator 硬拦。

### 2.3 事件系统 V2/V3（docs/54 / docs/55）
8. **引擎扩充**：`maxHp / hpPercent / gainCard / removeCard / upgradeRandom / gainEnhancement / loseRelic` 等效果与 `hpPercentAtLeast / pollutionAtLeast / loseableRelicAtLeast` 条件；条件不满足的选项统一置灰「需要 X · 当前 Y」。
9. **口径收紧**：军规 2 机器看守——事件 HP 收支绝对值 > 4 必须走百分比；`loseRelic` 池排除职业身份件；事件结算 HP 夹在 `[1, maxHp]`，不允许把玩家打到 0。
10. **文案去剧透**：全部事件选项标签去掉括号里的结果 / 赔率（甲方裁定）。

### 2.4 卡池与可读性
11. **职业 / 中立分池（docs/56）**：战斗奖励每槽 70% 本职业 / 30% 中立；101 张卡重归类为 血械 20 / 炉心 26 / 锈语者 35 / 中立 20。
12. **卡组查看页**：`/deck` 页（张数 / 类型分布 / 升级数 / 附魔数）。
13. **图鉴分类 + 升级预览**：全部 / 血械 / 炉心 / 锈语者 / 中立 副导航；点卡看原版 vs 升级后。

### 2.5 表现层与手感批次
14. **蓄力红屏改到释放帧**（`releaseFlash`，800ms 单次脉冲），蓄力期间信息交还敌人意图条。
15. **血链重做**（`consumeBoons`）：消耗自身全部加持（力量 / 再生 / 坚韧 / 荆棘 / 回血印记）与充能，每层 1 点伤害（升级 2 点）；负面状态不计数也不消耗。
16. **蚀锈改版**：敌方回合开始按当前层数结算、无视格挡、结算后 −5 层。
17. **音频层**：出牌 / 打中敌人 / 自己挨打 / 回合切换四条音效 + 循环氛围 BGM + 设置页三滑块试听；首次手势前静默、跳过动画一并静音。
18. **Bug 修复**：Boss 状态栏被玩家面板遮挡、颠倒 / 冰缓判定时点差一（敌人挂的诅咒在玩家出手前被扣没）、飞锈 `onHit` 能力永不派发（本次封版前最后一条）。
