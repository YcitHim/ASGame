## §一 净化事件：地图事件够不到战斗内状态（实现偏差，请裁）

docs/46 §5.3 的原话是「act2 事件批里给 1 个『净化』向事件（**移除全部诅咒/灼烧**并小回血）」。但九相有一条硬规则：**任何状态都活不过一场战斗**——诅咒/灼烧只存在于战斗状态里，而事件节点在战斗之外。**地图事件没有任何手段够到它们。**

当前实现（`sanctum_absolution`「净罪浅池」）落在**局外资源污染**上：

| 选项 | 效果 |
|---|---|
| 整身浸下去 | 污染 −100，HP −8 |
| 只洗手 | 污染 −40，HP +5 |
| 绕开池子 | 无事发生 |

**请裁一个：**

- **(A) 认了**（当前）：净化 = 净化污染，语义自洽（污染是本作的局外「诅咒资源」），零新机制。
- **(B) 做成战斗内效果**：事件给一个「下一场战斗开始时，清除自身全部诅咒/灼烧」的增益——需要给事件效果新增一类（`EventEffectKind` 加 `"battleBlessing"`），并让它跨节点带进战斗（RunState 加一个字段 + SCHEMA +1）。这是新机制，工作量不小但最贴原意。
- **(C) 改成遗物/能力**：把「净化」做成一件 T2 遗物（战斗开始时清除自身诅咒与灼烧），从遗物经济走，不进事件。
