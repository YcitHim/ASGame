## §一 必答

### Q1 · §三 说的「池内逐卡等概率 × 稀有度权重」与现行代码不一致，以哪个为准？
- docs/56 §三 尾注：「奖励按池内逐卡等概率 × **稀有度权重**抽取，池大只意味着种类多」。
- 现行代码（`rollCardRewards`，从 0.5 起就没变过）是**池内等概率**，没有稀有度权重——只有**事件显式池**那条路用了 `RARITY_WEIGHT`（starter 0 / common 3 / uncommon 2 / rare 1）。
- 我按「照旧」处理：本次**不动**权重，只改来源（职业 / 中立）。所以现在两种口径并存：战斗奖励等概率、事件显式池按稀有度加权。
- 三个选项：**(A)** 维持现状（**我的建议**：等概率 = 池子大小与抓取率直接挂钩，实测好读；且改权重要重记全部基线） **(B)** 战斗奖励也引入稀有度权重（要给一张权重表：rare 更稀有还是更常见） **(C)** 反过来把事件显式池也改成等概率（口径统一，改动小）。

### Q2 · 敌人状态芯片会盖在玩家面板上，接受吗？
- 修「Boss 状态栏被面板盖住」时，把 `.enemy-zone` 抬到战场带之上。副作用：**多敌同屏时，最左那只敌人的状态芯片会压在玩家面板的右上角**（截图 `reports/p26-multi-enemy-buffs.png`）。
- 取舍理由：状态是**战斗必须读的信息**（尤其 Boss 的灼烧/冰缓层数），面板是常驻容器——宁可让芯片压在面板上，也不能让芯片消失。
- 若你觉得压在面板上更丑：**(A)** 维持（**我的建议**） **(B)** 多敌时把敌人状态改到面板**下方**一条独立横带（要动布局，且与教学锚点 `data-tut-label="状态栏"` 有交互，需小改教学脚本） **(C)** 敌人状态只显字形与层数（去名字），从三排压到两排，几乎不再有机会压到面板。

## §三 蚀锈改版（甲方 2026-10-07 口头，已实装）

新规格：敌方回合**开始**按当前层数造成伤害 → **无视格挡**直扣生命 → 结算后**层数 −5**（归零即移除）。已同步 `rustspit` / `sanctum_quench` 的数据与文案，其余 8 张读写蚀锈的卡数值未动。详见 docs/38 末尾执行记录。

### Q6 · 衰减 5 层把小额应用打成了「一次性」，要不要重估锈语者入门卡的层数？
衰减 5 是一个**分水岭**：≤5 层的应用只能打一发就蒸发，≥10 层的应用能连着炸三回合。

| 卡 | 施加层数 | 旧版总伤害（duration 2） | 新版总伤害（衰减 5） |
|---|---|---|---|
| 锈唾 rustspit | 2（升级 3） | 4（6） | **2（3）** |
| 沥取场 leachfield | 2（升级 3） | 4（6） | **2（3）** |
| 瘴气 miasma | 2 | 4 | **2** |
| 蚀锈之枪 corrodelance | 4（升级 5） | 8（10） | **4（5）** |
| 黑色输血 blacktransfusion | 10（升级 12） | 20（24） | **15（18）** |
| 疫潮 plaguetide | 3（升级 4） | 6（8） | **3（4）** |

（新版总伤害 = 层数 + (层数−5) + (层数−10) + …；不足 5 层只有第一发。上表按「不再补刀」的裸收益算。）

方向上有好有坏：**大额应用更爆、小额应用更薄**，而且新版**无视格挡**（对高格挡敌人价值显著提高）。三个选项：
- **(A)** 先按新口径跑一轮 sim + 实测，拿数据再调（**我的建议**——别在没数的时候猜）。
- **(B)** 立刻把 ≤4 层的卡整体上调（例如锈唾 2→6、沥取场 2→6、瘴气 2→5、蚀锈之枪 4→8）。
- **(C)** 衰减从固定 5 改成「层数的一半」（曲线更平滑：2 层能打两回合），代价是规则不再是一句好记的「每回合 −5」。

## §四 事件选项去剧透（甲方 2026-10-07 裁定，已实装）

甲方原话：「把所有事件的（）全部删除啊，你把结果都写出来了，事件就失去了意义……别人都知道里面有什么了，肯定只选好的了。」

- **连带作废** docs/54 §二 军规 3「赌局明示赔率」与 §三 E8（validator 的百分比检查），退化为「赌局 weight 之和 > 0」。
- 唯一保留括号信息的是**条件门槛**（置灰小字），已把格式从 `需要 X（当前 Y）` 改成 `需要 X · 当前 Y`——它不是剧透，是「为什么点不动」的答案。

### Q7 · 「不闷赌」这道防线没了，要不要补一种「不剧透的可读性」？
现在玩家挑选项时读不到任何得失，赌局与普通选项的**风险量级**也读不出来（「投血」和「离开」在文案上一样轻）。如果实测反馈「选择靠蒙」，备选：
- **(A)** 维持现状（**先按甲方裁定跑**，实测看玩家是否真的在盲选）。
- **(B)** 选项文案给**档位词**：说风险量级、不说具体值（「小押」「大押」已经是这个路子，可以推广到全部赌局）。
- **(C)** 在**图鉴/教学**里公开赔率（老手查得到，第一次遇到时仍然未知）。
- **(D)** 选项旁给一个**模糊提示**（如「有得有失」「风险不小」），不负具体数字。
