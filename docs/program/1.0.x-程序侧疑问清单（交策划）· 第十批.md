## §一 必答

### Q1 · 血链升级值：程序暂定「每层 2 点」，要不要？
- 甲方原话是「每有 1 层造成 1 点攻击力」，升级没提。
- 原版血链的升级本来就是**空升级**（`upgraded: {}`，升级前后一字不差，见 `src/data/cards/_design-血械侍僧.md` 第 13 行）——重做后如果继续留空升级，一张 uncommon 的升级位就废了。
- 程序暂定升级 = 每层 2 点（筹码越多收益翻倍，方向明确的「加量」）。
- 选项：**(A)** 就这样（**我的建议**） **(B)** 维持空升级，等实测再说 **(C)** 换个升级法（比如「消耗后抽 1 张」）——你说一句我改。

### Q2 · 「有利状态」到底算哪些？程序口径如下，请确认
| 类 | 现状 | 是否算筹码 |
|---|---|---|
| 加持（力量 / 再生 / 坚韧 / 荆棘 / 回血印记） | docs/46 加持金 | **算**（每层 1 点） |
| 充能 | 炉心资源 | **算**（甲方点名） |
| 格挡 / 维续格挡 | 资源（`resource: true`） | **不算**：它已经在替玩家挡刀，再拿去换伤害等于收两道税 |
| 异常（虚弱 / 胆怯 / 污染 / 蚀锈 / 灼烧） | docs/46 异常红 | **不算也不消耗**（甲方：不包括负面状态） |
| 诅咒（冰缓 / 颠倒 / 眩晕） | docs/46 诅咒紫 | 同上 |

口径实现为 `BuffDefinition.polarity`（加持 / 异常 / 诅咒，docs/46 三色口径）+ `isBoonBuff()`，不是卡里写死的名单——以后加状态只需标极性，血链自动跟上。

## §二 记账（不用回）

### Q3 · 40% / 30% / 30% 到底是什么（甲方原问「以什么为基准」）
血链原来的 `multihit` 是：**把这张牌自己的 6 点伤害**按 40/30/30 拆成 3 段（最大余数法保证 2+2+2=6，不丢伤害）。**不是敌人最大生命的百分比**，也不是每段 6 点。

「能秒杀很多怪物」的真实原因不在比例，而在**多段各吃一次平A增幅**：力量/血怒是加在每一段上的，3 段就等于增幅 ×3（力量 5 时 3 段 ≈ 7+7+7=21）。重做成一次性兑现筹码后，这个「增幅 × 段数」的放大器就没了。

### Q4 · 蓄力红屏改到释放帧后，Boss 台词一起挪了
- 红屏只在 `ChargeResolved{released}` 那一帧出现（800ms 单次脉冲，不是常亮），蓄力期间不亮也不抢戏。
- `enemy.<id>.line.charge`（Boss 蓄力预警台词）跟着挪到释放帧——台词量不变，只是从「预告」变成「砸下来时喊」。若你想让台词留在蓄力期（红屏照旧只在释放），说一声，两件事可以分开。

### Q5 · 图鉴的「通用卡」分组已预留但当前为空
- 当前 101 张卡：血械侍僧 43 / 炉心机士 29 / 锈语者 29，**没有任何中立卡**。
- 副导航的「通用」按钮只在真的存在无职业卡时出现（`class` 不在职业表里即归入），以后加中立卡自动成组，不用回来改代码。
- 若你本来打算做中立卡池（比如事件专属卡、诅咒卡），那是另一批内容，说一声我们单独立项。

### Q6 · 卡组「背包」入口位置
- 挂在四个「远征进行中」页面的顶栏：战斗 / 地图 / 事件 / 锻造（奖励与休息页没有顶栏，暂未加）。
- 排序按「类型 → 费用 → 名字」，并给一句话摘要：`共 10 张 · 攻击 5 / 技能 5 · 已升级 0`。
- 若希望奖励页也能翻卡组（挑牌时最想看的其实是这个），说一声，我给奖励页补一个入口。
