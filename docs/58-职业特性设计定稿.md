# 58 · 职业特性设计定稿

> 整理：策划 · 2026-10-07
> 缘起：甲方裁定「角色辨识度不高，每个角色一个模子」，提出三职业特性初稿；经策划/程序评估（难度分级 + 四条疑问），甲方同日全部拍板，本文定稿。

## §一 拍板记录（2026-10-07，甲方）

1. **特性是开局选择**：工程师二选一（铁皮王八 / 玻璃大炮），且**所有职业都可以选「无特性」开局**。
2. **嗜血奖励按本回合累计**：累计造伤 + 累计自伤，本回合打的伤害、下回合回血。
3. **畸变 300 的「双倍效果」按程序建议改为「首张牌结算两次」**。
4. **畸变阈值掉下去就失去**：只在**战斗开局时**判定污染是否达到阈值；「胜利 −50」指战斗胜利后污染值直接减 50（例：150 → 100）。设计意图 = 逼玩家不断叠污染，颠覆原来「控制在 80 左右」的玩法。
5. **嗜血惩罚顺序**：先扣力量；力量没了（≤0）改上虚弱。

## §二 特性系统总规则

1. **开局三选（或二选）**：选定职业后、进入地图前，出现特性选择界面；选项 = 该职业全部特性 + 「无特性」。选择落入 `RunState.traitId`（存档 schema version +1 + migration，ADR-008）。
2. **特性全程绑定本局**，不可更换；无特性开局 = 纯现版玩法，作为对照组永久保留（也是 sim 基线对照）。
3. **实现纪律**：特性走**注册表**（新 `classTrait` 注册项，handler + params），禁止 classId 字符串特判（铁律 6）。挂载方式等同「开局自带的隐藏遗物」——复用触发器与修饰符管线。

## §三 属性调整

| 职业 | 血量 | 能量 |
|---|---|---|
| 血械侍僧 | 66 → **70** | 3 |
| 炉心机士 | 66 → **50** | 3 |
| 锈语者 | 66 → **60** | 3 |

- 属性与特性**解耦**：无特性开局也按新血量（工程师 50 血无特性是硬核挑战位，有意保留）。
- 工程师 −16 血是大砍，sim 三职业基线必须重跑对照（门禁口径见 §九）。

## §四 血械侍僧 · 嗜血

**惩罚段（回合末结算）**：本回合同时满足「未造成伤害」且「未消耗自己生命」→
- 力量 > 0：力量 −1；
- 力量 ≤ 0：改为获得 1 层虚弱（现有 weak：每层造伤 −10%，上限 5 层，不衰减）。

口径：
- 「造成伤害」= 玩家来源的 `DamageDealt.hpLost > 0`；**未击穿格挡的攻击不算**（hpLost = 0 不计）。
- 「消耗自己生命」= 卡牌 `bloodCost` / 血迹自伤；**受击掉血、反噬掉血不算**（与 docs/16 P2.3 回看口径同源，反例也同源）。

**奖励段（回合末结算）**：本回合累计造伤 ≥3 且累计自伤 ≥3 → 获得 2 层再生（现有 regeneration：回合开始按层数回血、持续 3 回合、可叠加刷新）。每多凑满一组 3+3 多给 2 层（即 `min(⌊累计造伤/3⌋, ⌊累计自伤/3⌋) × 2` 层）——再生在下个回合开始回血，即甲方所说「本回合打的伤害，下回合回血」。

数值（3/3/2层）为首版锚点，进 sim 观察清单，实测可调。

## §五 炉心机士 · 铁皮王八

1. **充能改道**：充能不再注入伤害修饰层（现状 resolve.ts 每层 +1 伤害），改为注入**格挡修饰层**——每次获得格挡时 +充能层数。
2. **格挡生荆棘**：当前格挡每 5 点 = 1 层荆棘（现有 bramble：每层反弹 3 点固定伤害），按光环实时派生（格挡变化即重算）；与卡牌直接施加的荆棘**加算**。
3. **荆棘上限对该特性开放至 10**（全局上限 5 不变，做成可按特性覆盖的参数）。

## §六 炉心机士 · 玻璃大炮

1. **充能上限突破 10**：本特性下充能不再触发超限反噬清零（现有 changeCharge 过载逻辑按特性关闭）。
2. **超负荷**（新减益， affliction / 层级型，战斗结束清零）：充能超出 10 的部分**每 3 点施加 1 层**；每层 = 获得时立即受 2 点伤害 + 每张卡获得的格挡 −1。
   - ⚠️ 回写事项：docs/46 原裁定「层级型为九相专用」，本稿甲方拍板为超负荷开口子，docs/46 需加注。
3. **首轮爆发**：每回合打出的**第一张攻击牌**附加等同于当前充能层数的伤害，打出后充能归零（消耗不经 changeCharge，不触发 onGainCharge——沿用现有「消耗不过载」口径）。

## §七 锈语者 · 超级大畸变

1. **污染无视上限**：本特性下污染不设 100 封顶；**每累计达到 100 的整数倍立即受一次反噬**（100/200/300/400…，反噬伤害沿用现常量 10，进 sim 观察清单），反噬后**不清零**，可继续突破。
2. **畸变阈值（战斗开局快照判定，局内不因跌破而失效，下一场开局重判）**：
   - **≥200 · 畸变触手**：每回合打出的第一张牌不耗能。
   - **≥300 · 畸变大鲨臂**：每回合打出的第一张牌**结算两次**（第二次不耗能；例：施加 2 点蚀锈 → 4 点）。
   - **≥400 · 畸变神眼**：每回合一次，从牌库中任选一张牌加入手牌（新选牌 UI）。
3. **战斗胜利：污染 −50**（例：150 → 100；不足 50 则归零）。
4. **既有压力源全部保留**：污染 ≥80 的临界惩罚（每回合开始 −2 HP）与所有污染卡/遗物互动不变——高污染的持续掉血是本特性的天然平衡阀。
5. 无特性锈语者玩法完全不变（100 封顶 + 触顶反噬照旧）。

## §八 实现口径（程序侧要点）

1. `RunState.traitId?: string` + 开局特性选择 UI（选完进地图）；存档 version +1。
2. 新注册表 `classTrait`（id / handler / params）；特性 handler 可挂：修饰层注入、触发器时机、战斗开局快照、战斗胜利结算。
3. 嗜血：Draft 新增两个回合计数器（dealtDamageThisTurn / selfHpSpentThisTurn，仿 `tookDamageThisTurn` 先例），回合末统一结算惩罚与奖励。
4. 铁皮王八：bramble `maxStacks` 参数化；充能修饰注入点按特性切换到格挡管线；荆棘光环在格挡变化后重算。
5. 玻璃大炮：changeCharge 的过载分支按特性关闭；新 buff `overload`（层级型）；「每回合第一张攻击牌」回合标记 + 消耗归零。
6. 大鲨臂「结算两次」复用栈式动作队列（第二次入队、免能、sourceId 同卡），**不加全局倍率上下文**。
7. 神眼：新动作类型 + 牌库选牌 UI（复用现有选卡组件骨架）。
8. golden replay 随改随录（老规矩）；sim 加 `--trait` 开关，三职业 × 有无特性出对照报表。

## §十 不做的事

- 不做特性之间的交叉组合（一局至多一个特性）。
- 不做特性的局内升级/成长。
- 不与排行榜联动（排行榜仍是独立未立项议题）。
- 不在本稿锁死任何数值——全部数值以 sim 对照 + 真人实测终审。
