# 03 · 修饰符管线与结算时序规范

> 对应 ADR-003。本文件属于**冻结规范**：管线顺序与 tick 顺序一旦确定，
> 后续所有卡牌、Buff、强化都按此设计，不得为单个内容破例。

## 1. 修饰符管线（Modifier Pipeline）

任何对外暴露的数值都按固定顺序逐层求值，每层产出可追溯的中间值（写进事件载荷）。

| 数值 | 求值顺序 | clamp |
|---|---|---|
| 卡牌费用 | 基础 → 升级 → 强化 → Buff → 本场临时 | ≥ 0 |
| 攻击伤害 | 基础 → 升级 → 强化 →（+力量/充能）→（×易伤/虚弱）→（-目标格挡）→ HP | ≥ 0；乘区在四舍五入一次 |
| 卖血代价 | 基础 → 强化（节油血契）→ 义体（血泵心脏）→ 遗物（破碎圣油瓶） | ≥ 0，可至 0 |
| 抽牌数 | 基础 → Buff → 本场临时 | ≥ 0 |
| 格挡 | 基础 → 升级 → 强化 →（×虚弱类修正） | ≥ 0 |
| 治疗量 | 基础 → Buff 修正 | ≥ 0 |

**规则：**
- 加区先于乘区；每个数值只有**一个**四舍五入点，写在上表。
- 每层修饰 = `{ sourceId, layer, op, value }`，禁止层间互相覆盖。
- 查询数值永远走管线，任何代码不得直接读"基础值字段"当最终值用。

## 2. Buff 层数规则

| 规则 | 约定 |
|---|---|
| 结构 | `{ id, stacks, duration, hooks }` |
| 同名叠加 | 默认 stacks 累加、duration 刷新；特例在 Buff 定义里显式声明 |
| 强度型 vs 回合计时型 | 力量=强度型（无 duration）；易伤/虚弱=计时型（每回合末 -1） |
| **参数语义（2026-10-05 策划 Q1）** | 强度型：参数=层数（力量/污染/格挡）；计时型：**参数=剩余回合数**（易伤/虚弱，卡面统一写「N 回合」）；再生=stacksAndTurns（参数=层数，默认 3 回合） |
| 衰减时机 | 固定在各相位 tick 结算，不允许" Buff 自己决定什么时候掉" |

## 3. 回合 tick 顺序（冻结）

**回合开始（turnStart）：**
1. 回合计时型 Buff duration -1，到期的发 `BuffExpired`
2. 再生（回血）→ 污染（按层数结算效果）→ 其他 start-of-turn 触发器（按注册序）
3. 能量重置 / 玩家格挡清除（**已拍板：各单位格挡在【自己】的回合开始清零**，杀戮尖塔式）
   - 玩家格挡：在玩家自己的 turnStart 清零；敌人回合期间保留
   - 敌人格挡：在敌人自己的行动相位开始前清零；玩家的整个回合期间保留（否则防御意图无效——2026-10-05 评审 P0-1 修正）
4. 抽牌

**回合结束（turnEnd）：**
1. 手牌关键词结算（保留 / 虚无 / 自动打出类）
2. end-of-turn 触发器（按注册序）
3. 敌人行动完成后进入下一回合 turnStart

**伤害结算（单次）：**
基础值 → 修饰管线 → 格挡吸收 → HP → 死亡检查 → 队列清理（ADR-002）

## 4. 决策记录（2026-10-05 全部拍板，无残留 ⚠️）

1. **格挡清零（2026-10-05 修正）**：**各单位在【自己】的回合开始清零**——杀戮尖塔式。
   - 玩家：玩家自己的 turnStart 清零；在敌人回合获得的格挡保留到下一个自己的 turnStart。
   - 敌人：敌人自己的行动相位开始前清零；其格挡必须撑过玩家的整个回合。
   - 历史注记：初版误写成"玩家与敌人都在玩家 turnStart 清零"，导致敌人防御意图完全失效（评审 P0-1）。
2. **污染满值反噬结算点**：污染值达到满值（100）时**立即结算**，紧随同一次动作的
   PollutionChanged 事件之后，不延迟到回合开始。
   回合开始 tick 2 只负责按层数结算常规污染效果；若 tick 2 使污染值到满，同样立即反噬。
   反噬本身产生的动作压入栈式队列（ADR-002），可被死亡清理规则取消。
3. **同相位触发器优先级**：默认按**注册序**；注册项可显式声明 priority（小者先执行），
   priority 相同时回落注册序。禁止内容层用「执行先后」做隐藏机制，需要顺序时必须显式写 priority。
