## §二 总方针调整：门禁从「sim 通关率」切换为「真人实测终审」

**甲方指令落地：即日起，sim 通关率不再作为任何批次的放行门禁。** 具体口径四条：

1. **健康区间（45%~60% / 30%~70%）暂停使用**。所有现存的通关率红字（10 层单幕 38.3%/31.5%、双幕 7.8%、血械 AI 下限 19.3%）一律**记为「观察基线」**，不是「不过」。它们唯一的用途是将来真人实测后对比「真人手感 vs sim 失真」的校准素材。
2. **sim 降级为「回归哨兵」**：保留三样——① golden replay（逐位一致，随改随录的老规矩不变）；② validator / 单测全绿（结构门禁不变）；③ sim 数字**照常跑、照常记录**，但只用于抓断崖式异常（单批次某职业波动 >10pp 要在执行记录里解释原因），不放行、不卡关。
3. **数值平衡的终审 = v1.1 封版前真人实测**，由甲方排期组织。框架见 §七，所有「sim 裁不了」的未决数值项统一转入**真人实测观察清单**（§七.3），不再在各批次疑问清单里反复横跳。
4. **docs/19 数值冻结协议同步修订**：「sim 复跑 30%~70% 健康、期望 45%~60%」一条暂停执行，替换为「golden 随录 + 哨兵记录 + 真人实测终审」。协议其余部分（改动批次化、一次一个变量、执行记录）不变。

> 说句实话：这条调整我是欢迎的。血械 19.3% 是「AI 不会放血」的失真、10 层 38.3% 是幕长账、双幕 7.8% 是第二幕未回落的老账——三个红字没有一个是九相本身的问题，却每一批都挡九相的路。闸门换得对。

## §七 真人实测门禁框架（✅ 2026-10-07 甲方签署，已据此封版 v1.1）

### 7.1 时机与规模

- 时机：**v1.1 封版前**（Phase 2b 完成 + docs/47 落地后），由甲方组织。
- 规模建议：≥5 名测试者 × 每人 ≥3 完整局，覆盖三职业 × 双幕。

### 7.2 记录口径

- 客观：职业 / 路线选择（贪稳自述）/ 死亡点 / 通关与否 / 各幕用时。
- 主观三项（1~5 分）：卖血手感 / 诅咒理解度 / 幕长疲劳度。

### 6. 偏差登记（须策划对账）

1. **净化事件无法「移除全部诅咒/灼烧」**。九相的硬规则是「任何状态都活不过一场战斗」，而地图事件在战斗之外——它够不到战斗内状态。当前实现落在**局外资源污染**上（整身浸下去：污染 −100 / HP −8），语义自洽但与原话不同。三个可选改法见第七批疑问清单。
2. **三张新卡的升级值是程序拟的**（docs/46 §5.2 只给了基础值），见第七批。


3. **压力表对非炉心职业是白板**：重做后它是通用 T1 件，但「充能」只有炉心吃得到。已列入第七批。
4. **`sim:companions` 口径未变**：仍按「开局携带」测各件强度；压力表重做后它的数字含义变了（现在是「开局 +2 充能的强度」），对账时注意。
