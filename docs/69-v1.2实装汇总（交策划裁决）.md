## §二 与设计稿的差异（7 条，请逐条追认或驳回）

### 2.1 骨架层是「必现」不是「必经」（docs/66 §3.2）

docs/48 有三条**冻结门禁**与「固定骨架」数学冲突：中段层宽度必 2~4、分支层含精英必含战斗、**同层精英 ≤1**。

**实现方式**：新增 ~pin~ 标注——该层**必现**一个指定稀有节点，但不动宽度、不动整层类型、不越任何配额。二幕 l3/l4/l6 与三幕 l3/l5/l6 都走它。

**差异**：
1. 玩家**可能从旁边的普通节点绕过**精英（要「必经」必须放宽宽度门禁）；
2. docs/66 §3.2 写的「l6 = **双精英**并列」**做不了**——「同层精英 ≤1」是冻结规则，现在是「必现一个精英」。

**回退成本**：删数据里 3 行 + 机制代码可留（三幕也要用）。要升级成真·必经请明示放宽哪一条门禁。

### 2.2 炉前督军阶段二用「灼烧」代替「蚀锈」（docs/66 §4.3）

设计写「污染 + 蚀锈」，但 ~corroding~ 蚀锈在引擎里是**敌人侧标记**（validator 明令只能施加给敌人），挂到玩家身上语义不成立。改用 ~burn~（灼烧）——与三幕「锻炉高温」同频，同样是逐回合压力。

**回退成本**：改 JSON 一行（但要先接受语义不自洽）。

### 2.3 锈心低语换了设计（docs/65 §6.2）

原设计「50% 敌人下一场开场 2 层虚弱」需要**新事件效果 + 一次存档 SCHEMA_VERSION 变更**，收益（一场虚弱）与成本不成比例。改成 **50% 得 1 件 T2 遗物 / 50% 污染 +10**——同样的赌博戏剧性，零引擎缺口。

**回退成本**：补一个 ~nextBattleDebuff~ 效果 + 存档迁移，中成本。

### 2.4 备选遗物两件**不是零成本**，我按新钩子实装了（docs/65 §6.3）

| 件 | 设计 | 实装方式 |
|---|---|---|
| 淬火怀表（T3） | 每场首次受 HP 伤害 → 2 层力量 | 新增遗物钩子 ~onDamaged~（真的掉 HP 才算），每场一次的保证走数据里的 ~once: "battle"~ |
| 赌徒齿轮（T2） | 开局 50% +3 能量 / 50% +8 污染 | 新增 ~chance~ 效果（加权分支，走独立 relic RNG 流，同种子同结果） |

原稿说「机制积木全部现成」，实测两个都要新钩子。已做完，但这是**引擎面扩大**，请知悉。

### 2.5 三幕暂时**没有自己的事件池**（文档没写这条门禁）

validator 强制「**事件池至少 6 个**」（docs/54 §六）。锻炉事件按 docs/65 只有 3 个，够不上设池下限，所以三幕现在**回落全局事件池**（会抽到一二幕的事件）。

**需要你定**：① 再补 3 个锻炉事件（我按同一口径设计也行）；② 给「终幕事件池」开一个豁免；③ 接受回落。

### 2.6 余烬引线走了**完整版**（docs/68 §2.3 曾建议降级）

新增 ~onExhaust~ 触发时机后，「打出消耗牌时抽 1」可以真的挂上去，不必降级。三职业的消耗流以后都能用这条时机。

### 2.7 炉心余温的「蓄力释放牌」口径（docs/68 §2.1）

按 **~spendCharge~**（真的把充能释放成伤害）判定，**不是** ~chargeCost~——实测 chargeCost>0 的只有两张技能牌、不造成伤害，按它判 +4 永远用不上。

## §三 本轮新增的引擎能力（你可以在后续设计里直接用）

| 能力 | 说明 |
|---|---|
| ~ActDefinition.rules~ | 幕级战斗规则：~mourning~（敌死挂蚀锈）/ ~forgeHeat~（第 N 回合起双方灼烧），参数走 ~params~ |
| ~MapLayerSpec.pin~ | 骨架层：该层必现精英 / 篝火 |
| ~StatMult~（幕 / 层 / 节点三级） | 敌人 HP / 造伤的幕内倍率，与难度倍率相乘；现状三幕遭遇 ×1.15/×1.1、l7 ×1.2/×1.15 |
| ~TriggerTiming += onExhaust~ | 「打出消耗牌」成为通用时机（强化 / 遗物共用） |
| ~EnhancementHandler.power~ | 强化可给某张牌注入常驻能力（炉渣镀层 / 余烬引线就是它） |
| ~EventEffect.tier~ | 事件掉遗物可按分级收窄（炉渣商人） |
| ~RelicHandler.onDamaged~ | 玩家真的掉 HP 时触发（淬火怀表） |
| ~CardEffect.chance~ | 概率分支效果（赌徒齿轮），独立 RNG 流、同种子同结果 |
| ~RunAchievements.finale~ | 真结局判定（不写死幕数，以后加第四幕不失效） |
