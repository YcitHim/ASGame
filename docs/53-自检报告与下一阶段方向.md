## §二 观察项（不是 bug，记账）

1. **三职业哨兵胜率悬殊**：炉心 32.0% vs 血械 6.5% / 锈语者 10.5%。docs/49 口径下不动数值，但这个差距已超出「职业风味」能解释的范围——**真人实测的第一优先级问题**，建议实测名单按「血械 → 锈语者 → 炉心」排。
2. **失控线爆发流**（血怒+低血沸腾同卡）：出现率 3.0%、对应胜率 33.3%、平均回合 18.7——出现率远低于 15% 警戒线，胜率也没超全局 +15pp，当前健康；但它是「爽点构筑」的种子，实测时留意玩家能不能自己发现它。
3. **精英战后 HP P50 = 23**（设计意图 ≥25）：略低于意图线 2 点，属「偏难」信号，进实测观察清单。
4. **奖励池稀释**：F2 六张转换卡进池后三职业哨兵全线微降（工程师 39.5→36.8 等），预期内，实测时关注转换卡的实际抓率与风评。

## §四 方向建议

**总判断：内容线接近满仓，风险已经全部从「做不完」转移到「没校准」。** 三职业胜率悬殊、精英战偏难、转换卡稀释——这些问题 sim 一律裁不了（docs/49 已定），堆新内容只会让实测变量更多。建议按以下顺序推进：

### 第一步：解锁 M3，把机制做「全」（实测前最后一批内容）
- 分裂是唯一锁着的机制。实测如果缺它，等于第二幕有一块的体验没验过，封版前还得再测一轮。
- 建议本周内发解锁令：分裂字段转正 + 鼓腹兽/藤壶寄居者/唱诗长 P3 挂载，走标准门禁（golden 重录 + 哨兵观察 + 单测）。
- **此后内容冻结**：不再进新卡新怪新机制，直到实测结论回来。

### 第二步：出整合构建，启动真人实测（最优先）
- 打一份包含全部已落地内容的稳定构建作为**实测候选版**。
- 实测清单在 docs/49 §七 基础上增补三条（来自 §二）：三职业胜率悬殊溯源 / 失控线爆发流可发现性 / 精英战偏难确认。
- 每职业至少 3 名测试者、每人完整 1 局起，按「血械 → 锈语者 → 炉心」顺序排期。

### 第三步：音频层与实测并行（不碰数值，不占实测变量）
- 出牌/命中（敌我两种）/回合切换 + 循环 BGM + 设置页滑块试听（docs/43 Q1 + docs/45 Q10 口径）。
- 音频是纯表现层，golden 应逐位一致，随时可插队的安全批次。

### 第四步：实测结论 → 数值校准批 → v1.1 封版
- 实测回来后开**数值校准批**：三职业平衡、精英战难度、转换卡抓率、T1 绝对线复审，一次性调完。
- 封版门禁：validator + golden + 真人复测签字，然后 v1.1「沉没圣堂」正式发布。

**一句话：先把锁着的分裂解开，然后冻结内容、全力保真人实测——这是当前杠杆率最高的事。**

### 第三步已完成：音频层（2026-10-07，纯表现层可插队批次）

范围照 docs/43 Q1 + docs/45 Q10 口径，一条不多：出牌 / 命中（打敌人、自己挨打**两种**）/ 回合切换 四条音效 + 一首循环 BGM + 设置页三滑块解禁并带试听。

**实现取向：Web Audio 程序化合成（`src/systems/audio`），零音频资源、零新依赖。**
仓库里至今没有任何音频素材，与其凭空塞二进制进去，不如先把音色做成可调参数（振荡器 + 滤波 + 包络）：调音 = 调数字，不用重新录音。将来策划给了真录音，只换 `playSfx` 内部实现即可，设置页与接线一行不用改。

| 音效 | 配方 |
|---|---|
| 出牌 | 高通噪声气声 + 三角波下坠（甩牌） |
| 打中敌人 | 带通 2400→900Hz 金属脆响 + 方波下坠 + 1320Hz 泛音 |
| 自己挨打 | 正弦 150→58Hz 低频闷响 + 低通噪声 + 锯齿下坠（跟飘字同主题） |
| 回合切换 | C5 + C4 低钟 + 带通咔哒 |

- **命中拆两种是硬要求**（docs/45 Q10：受击反馈是 v1.0.2 的主题）。两条都是 2 振荡器 + 1 噪声源，但波形 / 频率 / 滤波完全不同——单测直接比对「配方签名」，防止哪天被后人改成同一份。
- **「一首循环 BGM」在实现上是连续声场**（3 条失谐正弦 drone + 慢速 LFO 呼吸 + 循环低通水声垫）而不是音轨循环：第二幕沉没圣堂要的是氛围，一段旋律会听腻。
- 三条接线纪律：① 只有战斗动画事件链发声，玩家点「跳过」时声音一并跳过（不会在跳过整套连击时哐哐哐放完）；② 首次用户手势前不出声（浏览器自动播放策略）；③ 音量三分支各一条 GainNode，主音量或音乐拉到 0 即停 BGM，拉回来立刻复播。无 AudioContext（jsdom / 旧浏览器）一律 no-op 静默降级。
- 设置页：去掉 disabled 与「暂未开放」提示，新增试听行「出牌 / 打中敌人 / 自己挨打 / 回合切换 / 氛围 BGM（开停）」；音效滑块松手自动放一声样本——调音量当场听得到响度。

**门禁（数值零影响）**：golden **7 盘逐位不变**；validator 数字零改动（卡 101 / 敌 25 / 遗物 25 / i18n 752）；单测 **512 例 / 73 文件**（新增 p21-audio 8 例 + p21-audio-wiring 4 例）；lint / typecheck 全绿。

**真机核对**（headless Chrome，页内给 `AudioContext.prototype` 打点）：手势前 0 个节点 → 首次点击 +6 振荡器 / +1 循环噪声源（BGM 起来）→ 出牌 +3/+2（出牌音 + 打中敌人）→ 结束回合 +6（自己挨打 + 回合切换）→ 进入第 2 回合，**零控制台错误**。截图 `reports/audio-settings.png`。

顺手修掉一条与音频无关的**既有偶发失败**：`battle-view.spec` 的蓄力红屏用例假设「只有 enemies[0] 在蓄力」，而遭遇是随机掷的（别的敌人也能开局就蓄力点亮红屏）。已把其他敌人的意图清干净使判定确定化，连跑 3 次全过。
