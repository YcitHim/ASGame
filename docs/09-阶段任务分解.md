# 09 · 阶段任务分解与出口门禁（第一阶段 = 0.1）

> 用法：每个任务做完勾掉；**阶段出口门禁全绿才允许进入下一阶段**。
> 门禁不过 = 留在本阶段补，不欠债前进。欠债前进是 0.5 崩盘的头号原因。
> 上游依据：docs/07（里程碑）、docs/05（工程地基）、docs/02~04（技术规范）。

## 工作约定

- 任务粒度：0.5~2 天/个；超过 2 天的必须再拆
- 每完成一个任务：更新对应目录 README 的勾选项
- 每个阶段结束：开一次门禁评审（对着出口清单逐条过），结果记在本文件末尾「门禁记录」
