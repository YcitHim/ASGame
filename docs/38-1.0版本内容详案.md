**设计注**：
- **节奏闭环**：啜毒/锈钉/痛饮（吃毒）→ 蚀刃/毒膜/拾荒手（高危区增益）→ 泄毒咒/黑色输血/终点站（兑现）→ 净化窗口再来一轮。「吃—住—吐」三拍就是锈语者的回合语言。
- **终点站**是职业的谢幕一击：14 + 8 层蚀锈 ×3 = 38 的 3 费重锤，对标炉心过载（40）与血械放干（27+），三职业各有一记「教科书最后一页」。
- **九十九**是本批最大胆的一张：把「反噬」这个全局惩罚改写成一次性收益——它是 1.0-B 的名片，也是真人实测的重点观察对象；若实测证明反噬改写破坏了污染的威胁感，降级备选：改为「污染 95+ 时不再增长」（保住走钢丝，删掉暴富）。
- **红区栖者**若条件修饰管线来不及，降级备选：skill 1 费「消耗：污染 ≥80 时获得 3 力量」。
- 强化对位：淬锈（onHit 易伤）/血怒（低血增伤）等对锈语者的多段与 DoT 均有意义；DoT 不吃力量与充能加伤（固定伤害口径，与反伤一致——写进 validator 规则防回归）。

### 数值与验证

- 普通档 400 局：**血械 49.5% / 炉心 46.5%**，均落 45~65%（未触发 §一.5 预案）。
- 关键发现：旧 `rollRelicChoices` 是**字母序取前 N**（精英永远同样三件）；改为 reward 流随机后，池子扩大才真正生效——修正前炉心一度 42.0%，修正后 46.5%。
- golden 六盘哈希**逐盘未变**（战斗路径未动）；validator 通过（卡 64 / 强化 8 / 敌 7 / 遗物 24 / 事件 5 / 职业 2 / 关卡 1 / i18n 436）；单测 **298 例 / 48 文件**；CI 全绿。
