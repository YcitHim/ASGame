# tests/ · 测试

## unit/ · 单元测试（Vitest）

覆盖清单（对应铁律 4：每个关键词、每个 Buff 必须有单测）：

- [ ] **pipeline**：修饰符求值顺序、乘加区与取整点、栈式插队、死亡清理、多段拆分
- [ ] **buffs**：六个 Buff 的叠加/刷新/tick 顺序（锚定 docs/03 §3）
- [ ] **keywords**：九个关键词各钩子
- [ ] **rng**：同种子同序列、流间互不污染、shuffle 确定性
- [ ] **强化钩子**：modifyCard / onHit（血之螺栓三连击）
- [ ] **洗牌抽牌**：耗尽重洗、消耗堆、保留/虚无结算
- [ ] **存档**：migration 链 v0→当前

1. 用调试控制台 + 固定 seed 录几盘标准对局（`{ seed, actions[] }`）

3. CI 重放并断言：**事件序列逐条一致**（重构的照妖镜）
