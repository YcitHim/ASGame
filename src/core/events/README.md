# events/ · 领域事件

## 职责
核心层对外的唯一表达。UI 动画、战斗日志、回放、调试面板全部从这里消费。

## 待做清单

- [ ] `DamageDealt` 载荷含修饰层明细（每层 sourceId + 贡献值）——硬性要求
- [ ] 事件分组：同一 Action 产出的事件归为一个动画帧组（供 UI 并行表现）

## 约束
- 事件不可变，产出后不再修改
- 新增事件 = 追加新类型，不改旧事件结构（回放兼容性）
