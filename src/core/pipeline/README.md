# pipeline/ · 效果管线（本项目的心脏）

## 职责
1. **栈式动作队列**：出牌判定 → 入栈 → 触发器拦截 → 逐条结算 → 连锁触发压栈 → 事件输出
2. **修饰符管线求值器**：一切数值按 docs/03 §1 的层级表求值，产出每层明细
