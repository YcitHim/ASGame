# enemies/ · 敌人数据（属性 + 意图表）

## 单敌 JSON 要点
- 属性：HP 区间（combat RNG 取）、格挡、抗性
- 意图表：权重 + 条件分支 + 连续限制；类型见 `core/intents/README.md`
- 预留：多段行动 / summon / 阶段转换（P2 换表）字段
