## 事件 JSON 要点（预留结构）
- `id` / i18n 文案 key（标题、描述、各选项文案）
- `choices[]`：每项 = `{ condition?, effects[] }`，效果引用已注册 handler/修饰
- 结果可走 reward RNG 流（概率分支）
- 事件与世界观三系机制挂钩：卖血换奖励 / 污染换强度 / 充能换遗物
