# enhancements/ · 卡牌专精强化数据

## 规则（设计依据：原方案 §六 + ADR-005 修订）
- 强化附着在**卡牌实例**上：`CardInstance = { cardId, enhancements[] }`，随存档持久化
- 每卡 3 个强化槽；T1 通用（数值向）/ T2 专属（改玩法，绑定特定卡）
- 同一强化不可重复；`mutex` 互斥需对称声明
- 生效挂载点只有两个：`modifyCard`（出牌前改形态）/ `onHit`（命中计数）

见 docs/04 §3（handler + params 模式）。
